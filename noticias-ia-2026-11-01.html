Aplicaciones profesionales de IA

🔥 Vercel Labs lanza agent-desktop: computer-use open-source para agentes de coding

Vercel Labs publicó agent-desktop, un CLI en Rust + librería C (Apache 2.0) que da a agentes de coding la capacidad de operar el sistema operativo completo en macOS, Windows y Linux. En vez de screenshots, lee el accessibility tree nativo (AX API, UI Automation, AT-SPI), lo que lo hace más rápido y preciso.

Si construyes agentes que necesitan interactuar con apps de escritorio o automatizar flujos fuera del browser, esto elimina la dependencia de APIs propietarias de computer-use.

ShiftDelete • Vercel Changelog

🔥 OpenAI Decisions API llega a Vercel AI Gateway: respuestas estructuradas sin generación

La Decisions API de OpenAI (endpoint /v1/decisions) ya está disponible en Vercel AI Gateway. A diferencia de los modelos generativos, los modelos de decisión devuelven respuestas estructuradas directas sin generar texto, optimizados para clasificación, routing y toma de decisiones en pipelines.

Para tu backend de marketplace o app, esto simplifica enormemente los flujos de routing y clasificación sin tener que parsear texto generado.

Vercel Changelog

GPT-6.1 Terra disponible en API: el modelo de OpenAI para computer-use y razonamiento visual

GPT-6.1 Terra está disponible vía API con contexto de +1M tokens, optimizado para razonamiento visual, control preciso de computadora y escritura natural. Variante fast disponible para aplicaciones de baja latencia.

Con +1M de contexto y computer-use nativo, es una opción seria para agentes que necesitan procesar documentos largos o automatizar tareas en desktop.

Google Gemini 4 Carbon: el modelo más fuerte de Google, enfocado en cybersecurity y tareas largas

Google anunció Gemini 4 Carbon el 28 de octubre, posicionándolo como su modelo más capaz. Destaca en ciberseguridad y tareas de larga duración, áreas donde los modelos anteriores tenían limitaciones.

🔥 VoxNexus lanza VoxEdge: voice AI on-device para Android sin conexión

VoxNexus presentó VoxEdge, una plataforma de voz AI que corre reconocimiento y síntesis de voz directamente en dispositivos Android sin necesitar internet. Diseñada para mercados con conectividad limitada.

Para apps Android que necesitan voz offline (field workers, delivery, mercados emergentes), esto resuelve el problema de dependencia cloud que bloqueaba muchos casos de uso.
