Aplicaciones profesionales de IA

🔥 OpenAI lanza GPT-Live: voz full-duplex que escucha y habla al mismo tiempo

OpenAI presentó GPT-Live, una nueva generación de modelos de voz con arquitectura full-duplex que permite escuchar y hablar simultáneamente, con backchannels naturales (“mhmm”, “sí”) y delegación automática a GPT-5.5 para consultas complejas. GPT-Live-1 será el modelo de voz por defecto en ChatGPT para usuarios de pago; GPT-Live-1 mini para usuarios gratuitos, disponible en iOS, Android y web.

Si tu producto tiene cualquier capa conversacional (coaching, soporte, marketplace de servicios), ahora tienes un competidor de voz en tiempo real contra el que construir o que integrar.

Microsoft comienza a reemplazar OpenAI y Anthropic con modelos MAI propios en Office

Microsoft está enrutando decenas de miles de prompts semanales en Excel y Outlook a través de sus propios modelos MAI en lugar de OpenAI y Anthropic. La estrategia es selectiva: tareas rutinarias de alto volumen van a MAI, mientras tareas complejas siguen con modelos externos.

Señal clara de que las grandes plataformas internalizan costos de AI — si tu producto depende de una sola API, construye valor defensible por encima de la capa del modelo.

Innovaciones técnicas con potencial práctico

🔥 SpaceXAI lanza Grok 4.5 con Cursor: modelo de coding “clase Opus” a mitad de precio

SpaceXAI presentó Grok 4.5, el primer modelo co-desarrollado con Cursor tras la adquisición de $60B. Entrenado en datasets de coding, ciencia e ingeniería, se posiciona como “Opus-class pero más rápido y eficiente” a $2/$6 por millón de tokens (input/output). Disponible en Grok Build, Cursor y la consola de SpaceXAI.

Otro modelo fuerte de coding a precios agresivos que presiona los costos de API hacia abajo — ideal para pipelines de coding agente o dev tools que necesitan volumen.

SpaceXAI • Cursor • VentureBeat

GitHub Copilot integra Kimi K2.7 Code: primer modelo open-weight en el ecosistema

GitHub hizo GA de Kimi K2.7 Code de Moonshot AI en el model picker de Copilot (Pro/Pro+/Max desde julio 1, Business/Enterprise desde julio 7). Es un modelo MoE de 1T parámetros que activa solo 32B por token, hosteado en Azure. Los admins deben habilitar la política para su org.

Modelos open-weight entrando al tooling mainstream de IDE significa que puedes elegir entre propietario y auditable/self-hostable dentro del mismo workflow.

GitHub Changelog • TechTimes

🔥 OpenAI Flex Processing: 50% de reducción en costos de API para tareas asíncronas

OpenAI lanzó en beta Flex Processing, que ofrece precios de Batch API para uso per-request a cambio de tiempos de respuesta más lentos. Para GPT-5.5 esto significa ~$2.50/$15 por millón de tokens en lugar de $5/$30 — un recorte del 50% para cargas que toleran latencia.

Si tu producto tiene cualquier pipeline asíncrono (enriquecimiento de datos, generación de contenido batch, agentes en background), puedes cortar tu factura de API a la mitad sin cambiar de proveedor.

Creación de negocios y productos con IA

🔥 Modelos chinos alcanzan 30-46% del uso de API en plataformas de EEUU

Una investigación de CNBC confirmó que los modelos AI chinos (open-source) representan entre 30% y 46% del uso de tokens de API enterprise a través de plataformas de desarrolladores en EEUU, consistentemente arriba del 30% cada semana desde febrero. Estos modelos cuestan 60-90% menos que los líderes de Anthropic y OpenAI.

El arbitraje de costos es real y se acelera — una estrategia multi-modelo donde ruteas tareas no-críticas a modelos baratos y reservas frontier para lo difícil ya es table stakes.

🔥 Claude Sonnet 5 es ahora el modelo default: 1M de contexto a $2/$10 por Mtok

Anthropic hizo de Claude Sonnet 5 el modelo por defecto para todos los usuarios Free y Pro, con ventana de contexto nativa de 1M tokens y pricing promocional de $2/$10 por Mtok hasta el 31 de agosto (luego $3/$15). Está diseñado para trabajo agéntico sostenido: coding multi-archivo, debugging, tool use y workflows autónomos.

Un modelo agéntico de 1M de contexto a $2 input es la opción frontier más barata para construir agentes de coding y workflow — ideal para bootstrappear desarrollo de producto con Claude Code.

🔥 Claude Cowork se expande a web y móvil: sesiones que corren en la nube

Anthropic lanzó Claude Cowork en web (claude.ai) y móvil (iOS/Android), con sesiones ejecutándose remotamente en la nube. Puedes iniciar una tarea en tu escritorio, revisar el progreso desde tu teléfono, y el trabajo continúa aunque cierres tu laptop. Disponible primero para usuarios Max, con límites de uso duplicados hasta el 5 de agosto.

Para un founder solo o equipo pequeño, esto convierte a Claude en un worker asíncrono siempre activo — lanza un code review o análisis de datos y monitorea desde tu teléfono.

Universidad de Chicago crea parche AI on-body que diagnostica arritmias con 99.6% de precisión

Investigadores de UChicago desarrollaron un parche flexible con computación AI integrada que analiza datos de salud directamente en el cuerpo sin enviarlos a la nube, entregando diagnósticos en milisegundos. Logra 99.6% de precisión identificando arritmias cardíacas potencialmente mortales.

Edge AI en wearables médicos con precisión clínica abre oportunidades para plataformas de monitoreo de salud que no dependen de conectividad.
