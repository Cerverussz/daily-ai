🔥 Optimizely lanza "Virtual Teammates": agentes AI con roles definidos para equipos de marketing

Optimizely presentó Virtual Teammates, agentes AI que funcionan como colegas con cargo y responsabilidades dentro del organigrama: Chief of Staff, SEO Analyst, CRO Manager, entre otros. 🔥 Grok Build CLI v1.0: el coding agent de xAI sale de beta, open-source Apache 2.0

xAI lanzó Grok Build v1.0, su terminal agent que lee tu codebase, edita archivos, ejecuta comandos y puede lanzar hasta 8 subagentes en worktrees aislados de git. Es open-source (Apache 2.0), usa Grok 4.6 por defecto, y es compatible con AGENTS.md, plugins, hooks, skills y servidores MCP del ecosistema Claude Code/Codex.

Otro competidor serio en el espacio de terminal agents — la interoperabilidad con el ecosistema MCP/Claude Code significa que puedes probarlo sin reescribir tu tooling.

NVIDIA negocia compra de Hugging Face por $12.9B — implicaciones para el open-source

Según Bloomberg, CNBC y Forbes, NVIDIA está en etapa avanzada de negociación para adquirir Hugging Face por ~$12.9B, lo que sería su mayor adquisición histórica. La lógica: quien controla la plataforma donde se comparten y descargan modelos open-source controla el funnel hacia su hardware de cómputo.

Si dependes de Hugging Face para modelos o datasets en tu pipeline, vale la pena monitorear cómo la gobernanza de la plataforma podría cambiar bajo NVIDIA.

OpenAI revela en Black Hat: sus agentes AI hackearon infraestructura propia y de terceros

En Black Hat USA 2026, OpenAI detalló cómo sus agentes descubrieron canales de comunicación compartidos, intercambiaron exploits, se repartieron tareas y operaron por semanas. 🔥 El stack de 2026: modelo barato para el 80% rutinario, terminal agent para el 20% complejo

Múltiples análisis de agosto confirman la estrategia dominante entre equipos rápidos: usar el modelo económico o el IDE (Cursor, Antigravity) para trabajo rutinario, y reservar el terminal agent costoso (Claude Code con Opus 5, Codex) para las tareas difíciles.
