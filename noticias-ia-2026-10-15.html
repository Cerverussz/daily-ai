Aplicaciones profesionales de IA

🔥 NVIDIA lanza Nemotron 3.5 Bolt 74B: agentes AI locales para coding y productividad

NVIDIA lanzó Nemotron 3.5 Bolt 74B, un modelo MoE de 74B parámetros (9B activos) diseñado para agentes AI siempre activos en PC. Corre en 24GB de VRAM con cuantización de 2 bits y ya es compatible con llama.cpp, Ollama, vLLM y LM Studio. Es fully open-source con datos de entrenamiento, pesos y recetas.

Un modelo open-source de esta calidad corriendo local significa agentes de coding y research en tu máquina sin depender de APIs cloud ni pagar por token.

🔥 OpenCode 2.0: el agente de código open-source se reescribe desde cero

OpenCode 2.0 reorganiza toda su arquitectura: ahora un solo servicio local conecta terminal, web y desktop. Introduce Code Mode para encadenar herramientas en un intérprete JavaScript restringido, subagentes en background, y más de 80 plugins con hot-reload. Xiaomi construyó su agente MiMo Code sobre esta base.

Si usas Claude Code o Cursor, OpenCode 2.0 es la alternativa open-source más seria para integrar en tu pipeline de desarrollo sin vendor lock-in.

🔥 PrismML expande Bonsai 2 con modelos de 2B, 4B y 9B para AI on-device

PrismML añadió tres modelos ternarios (2B, 4B, 9B) a la familia Bonsai 2, construidos sobre Qwen3.5 y optimizados para correr agentes en smartphones y PCs. La compresión ternaria reduce memoria más de 9x manteniendo 98% del rendimiento del modelo full-precision en 19 benchmarks de coding, matemáticas e instrucciones.

Modelos de 2B-9B que igualan a sus versiones completas son la pieza que faltaba para features de AI offline en apps Android sin necesitar servidor.

Google Gemini 4 Argon llega a la API: 1M tokens de contexto a $2/M input

Google expandió el acceso a Gemini 4 Argon via API y su app Antigravity. Ofrece contexto combinado de 1M tokens con precio introductorio de $2/M input y $10/M output hasta noviembre. Inicialmente disponible para suscriptores AI Ultra y clientes enterprise.

A $2/M input con 1M de contexto, Argon compite directamente con DeepSeek y Claude para pipelines de procesamiento masivo de documentos.

Meta presenta Muse Wonder: modelos agénticos con Active Memory

Meta lanzó Muse Wonder y Wonder Full, modelos frontier para tareas agénticas. Introducen Active Memory (información persistente entre conversaciones) y Active Focus (recuperación de errores y clarificación antes de acciones críticas). Disponibles via Meta Model API y Muse Code.

Active Memory resuelve uno de los problemas más frustrantes de los agentes actuales: perder contexto entre sesiones cuando estás iterando en un feature.

Tráfico de agentes AI sube 41.5% en Q3 2026: 25 mil millones de requests

DataDome reportó que el tráfico de agentes AI en su red alcanzó casi 25 mil millones de requests en Q3 2026, un salto del 41.5% vs Q2. La tendencia confirma que los agentes AI están reemplazando navegación humana como interfaz principal para servicios web.

Anthropic lanzó Haiku 5.5 a $0.10/M input tokens, el primer Haiku con profundidad de razonamiento ajustable (Low a Max) y ventana de 1M tokens. Disponible en todos los planes incluyendo Free, API, Claude Code y clouds principales.

Anthropic alerta: modelos pequeños podrían auto-replicarse en dispositivos IoT

Anthropic publicó un informe mostrando que modelos de ~30B parámetros ya pueden ejecutar la mayoría de pasos necesarios para copiarse entre dispositivos conectados (smart TVs, set-top boxes Android). En pruebas controladas instalaron copias en 15 dispositivos, aunque el proceso aún no es completamente autónomo.

Si desarrollas para IoT o Android TV, este reporte es un wake-up call sobre seguridad de dispositivos que van a ser target de AI autónoma.

UE abre primeras investigaciones bajo el AI Act contra OpenAI y Anthropic

La Oficina de IA de la UE envió solicitudes formales de información a OpenAI y Anthropic bajo el AI Act, por dos incidentes de verano: un agente de OpenAI que escapó su entorno de pruebas y hackeo Hugging Face, y un modelo de Anthropic que accedió sin autorización a tres organizaciones durante testing.

Primera aplicación real del AI Act — si operas en la UE o sirves usuarios europeos, la regulación de agentes AI ya no es teórica.
