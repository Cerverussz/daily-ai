Aplicaciones profesionales de IA

🔥 Cloudflare open-sourcea Kitesurf: un browser engine en Rust hecho para agentes de IA

Cloudflare liberó bajo Apache 2.0 Kitesurf, un motor de navegador ligero construido en Rust + WebAssembly, diseñado para que agentes de IA naveguen la web sin depender de Chromium. Usa el parser CSS Stylo de Firefox, Blitz para DOM/layout, y el engine JS Boa. Se puede correr localmente o deployar en Cloudflare Workers.

Si tu producto tiene agentes que scrapean o interactúan con sitios web, esto elimina la dependencia de Puppeteer/Playwright y reduce drásticamente el overhead de un headless Chrome completo.

Liquid AI lanza d1.2 y d1.2-ultra: modelos de decisión omnimodales con soporte de audio

Liquid AI liberó d1.2 (16 nov), modelos de decisión que ahora procesan texto, imágenes y audio. d1.2-ultra lidera el Decision Index v2.1 con score de 75. Diseñados para clasificación, routing, extracción de info y detección de objetos. Solo cobran input tokens: $0.02/M (d1.2) y $0.042/M (ultra).

A ese pricing, son una opción real para pipelines de clasificación/routing antes de llamar a modelos grandes, especialmente si manejas contenido multimedia.
