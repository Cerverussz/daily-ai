🔥 Cursor lanza app nativa para iOS: agentes de coding desde el celular

Cursor (Anysphere) lanzó su primera app nativa para iOS en beta pública para todos los planes de pago. Permite lanzar agentes de coding en la nube, controlar remotamente agentes del desktop, revisar diffs, mergear PRs y usar input de voz desde iPhone o iPad.

Tesla limita gasto en IA a $200/semana por ingeniero, Uber y Meta siguen la tendencia

Vulnerabilidad crítica en LiteLLM (CVE-2026-42271) expone API keys de todos los proveedores AI

Un fallo de command injection en el MCP server preview de LiteLLM (v1.74.2–1.83.6) permite ejecución remota sin autenticación con score CVSS 10.0, exponiendo todas las API keys configuradas (OpenAI, Anthropic, Gemini, Azure, Bedrock). CISA lo agregó al catálogo de vulnerabilidades explotadas activamente.

Si usas LiteLLM como proxy multi-modelo (setup común), actualiza a v1.83.7+ inmediatamente y rota cada API key que haya pasado por instancias afectadas.

🔥 Meituan open-sourcea LongCat-2.0: modelo de coding de 1.6T parámetros bajo licencia MIT

Meituan publicó LongCat-2.0 bajo MIT — un modelo MoE de 1.6 trillones de parámetros con contexto nativo de 1M tokens que activa solo 48B parámetros por token. 🔥 Agent Marketplaces emergen como el nuevo App Store para servicios autónomos

En Q2 2026, ocho marketplaces de agentes han consolidado ecosistemas distintos: Claude Skills, GPT Store, MCP Hubs, Hugging Face Spaces, Replit Agent Market, LangChain Hub, Vercel Agent Gallery y Cloudflare AI Marketplace. Claude y ecosistema Anthropic

🔥 Anthropic lanza Claude Apps Gateway para Amazon Bedrock y Google Cloud

Lanzado el 2 de julio, el Claude Apps Gateway es un contenedor self-hosted y stateless que provee SSO corporativo, políticas centralizadas, control de acceso por roles, atribución de costos por usuario y caps de gasto para Claude Code en entornos enterprise. Rutea inferencia a la Claude API, Amazon Bedrock o Google Cloud con failover opcional entre proveedores.

Si estás armando un equipo de producto alrededor de Claude Code, este gateway resuelve los mayores puntos de fricción (onboarding, control de costos, policies) sin requerir infraestructura custom.

🔥 Claude Sonnet 5 es ahora el modelo default para todos los usuarios Free y Pro

Lanzado el 30 de junio y default desde el 1 de julio, Claude Sonnet 5 es el Sonnet más agéntico de Anthropic con mejoras sustanciales en razonamiento, tool use, coding y trabajo de conocimiento.
