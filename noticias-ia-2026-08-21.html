Innovaciones técnicas con potencial práctico

🔥 Cloudflare Kitesurf: browser para AI agents que usa 7x menos memoria que Chromium

Cloudflare lanzó Kitesurf en beta, un browser construido desde cero con WebAssembly sobre Workers, usando el CSS parser de Firefox y el engine JS Boa en Rust. Se activa con un parámetro browser=kitesurf en tu código Puppeteer/Playwright existente, compatible con CDP.

Si tus agentes hacen scraping o interactúan con web, esto reduce dramáticamente el costo de infra por sesión de browser sin cambiar tu código.

TechCrunch • Cloudflare Changelog

🔥 Vendo (YC S26): deja que tus usuarios construyan features sobre tu producto con agentes

Vendo es una capa de personalización open-source que permite a los usuarios de tu SaaS crear sus propias features, automatizaciones e integraciones usando tu API existente, todo renderizado en tu tema y ejecutado en sandboxes seguros. Incluye un agente listo para producción con UI generation y knowledge base.

Si construyes un marketplace o SaaS, esto resuelve el problema del backlog infinito de features: tus usuarios se las construyen solos, sobre tu API, sin tocar tu código.

Anthropic activa watermarks invisibles en todo el output de Claude globalmente

Desde el 2 de agosto, todo texto y archivo generado por Claude lleva watermark invisible para cumplir con el EU AI Act (Art. 50). Usa el estándar C2PA para archivos. El watermark no identifica al usuario, sobrevive ediciones ligeras, y se elimina solo con reescritura completa.

Si integras Claude en tu producto, tus usuarios recibirán contenido watermarked por defecto; evalúa si eso afecta tu caso de uso o si necesitas comunicarlo.
