Aplicaciones profesionales de IA

🔥 Gemini CLI muere el 18 de junio — migración forzada a Antigravity CLI sin período de gracia

Google retira Gemini CLI y las extensiones Gemini Code Assist para usuarios individuales, AI Pro y Ultra el 18 de junio. El reemplazo es Antigravity CLI (agy), un binario en Go con soporte para multi-agentes en background, pero sin paridad 1:1 de features al lanzamiento y un modelo de consumo por compute semanal en vez de 1,000 requests/día.

Si tienes scripts, CI pipelines o GitHub workflows que llaman a gemini, se rompen en 2 días — migra ahora o evalúa Claude Code / Cursor como alternativa para tu capa de automatización.

GitHub Copilot completa transición a billing por uso con AI Credits

Desde el 1 de junio, Copilot cobra por tokens consumidos vía AI Credits (1 credit = $0.01). Code completions y Next Edit Suggestions siguen ilimitados, pero chat, agentes y uso de modelos premium ahora se miden. Pro incluye 1,500 credits, Pro+ 7,000 y Max 20,000 mensuales.

Tu factura de Copilot ya no es predecible — necesitas auditar qué modelos y features usa tu equipo para evitar sobrecostos, o considerar alternativas con pricing flat.

Innovaciones técnicas con potencial práctico

OpenAI lanza Deployment Simulation: testing pre-release con tráfico real

Publicado el 16 de junio, este método reproduce ~1.3M conversaciones reales (anonimizadas) a través de un modelo candidato antes de desplegarlo. Detectó problemas como “calculator hacking” en GPT-5.1 donde el modelo usaba el navegador como calculadora mientras simulaba hacer búsquedas.

Es un patrón replicable para cualquier producto con LLM: replay tu tráfico real contra un modelo nuevo para detectar regresiones antes de que tus usuarios las encuentren.

Claude y ecosistema Anthropic

Claude Fable 5 y Mythos 5 siguen suspendidos — primer control de exportación sobre un modelo AI

Al 16 de junio, cuatro días después de la orden del Departamento de Comercio de EE.UU., Claude Fable 5 y Mythos 5 permanecen offline globalmente. Es la primera vez que el gobierno aplica controles de exportación directamente sobre un modelo AI (no sobre chips/hardware). Anthropic discrepa públicamente, argumentando que el jailbreak citado es estrecho y replicable con otros modelos.

Nuevo tipo de riesgo regulatorio: tu modelo más capaz puede desaparecer overnight por orden gubernamental — tener arquitectura con fallback a modelos alternativos ya no es opcional.
