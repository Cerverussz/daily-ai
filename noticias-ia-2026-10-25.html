Claude Haiku 5.5: 75% más barato que Haiku 4.5, con control de esfuerzo configurable

Anthropic lanzó Haiku 5.5 a $0.10/M input y $0.50/M output (vs $1/$5 de Haiku 4.5). Es el primer Haiku con niveles de esfuerzo ajustables, permitiendo elegir entre velocidad y calidad de razonamiento según la tarea. Haiku 4.5 se retira el 15 de octubre.

A estos precios, Haiku 5.5 es viable para clasificación masiva, routing de intents, y cualquier tarea de alto volumen donde antes usabas regex o heurísticas.

Releasebot - Claude Updates

Claude Code 2.1.304: fork subagents por defecto y /auto-mode-setup

En octubre, Claude Code avanzó de v2.1.290 a v2.1.304 con cadencia rápida. Los cambios más relevantes: fork subagents activados por defecto (v2.1.302), control de esfuerzo para sub-agentes, idle compaction para mejor uso de contexto, y el nuevo comando /auto-mode-setup.

Fork subagents por defecto significa que tareas complejas se paralelizan automáticamente — si no has actualizado Claude Code en semanas, la diferencia de productividad es notable.
