🔥 Supply chain attack vía Nx Console en VS Code roba credenciales de Claude Code y GitHub

El grupo TeamPCP comprometió Nx Console (v18.95.0) en el VS Code Marketplace por 18 minutos el 18 de mayo, exfiltrando ~3,800 repos internos de GitHub. El payload se disfrazó como “setup de MCP” y es el primer supply chain attack diseñado para robar configuraciones de AI coding assistants (~/.claude/settings.json), tokens npm, AWS y 1Password.

Audita tus extensiones de VS Code y rota credenciales si usaste Nx Console esa semana; la superficie de ataque ahora incluye tus configs de AI.

Claude y ecosistema Anthropic

Anthropic lanza Self-Hosted Sandboxes y MCP Tunnels para Claude Managed Agents

Anunciado en Code with Claude London (19 mayo), self-hosted sandboxes (beta pública) permite ejecutar herramientas de agentes en tu propia infra (Cloudflare, Daytona, Modal, Vercel) mientras Anthropic maneja orquestación.
