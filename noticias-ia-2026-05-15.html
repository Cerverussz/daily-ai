Sakana AI RL Conductor: un modelo de 7B que orquesta GPT-5, Claude y Gemini mejor que cada uno solo

Sakana AI presentó en ICLR 2026 el RL Conductor, un modelo de 7B parámetros entrenado con reinforcement learning que no resuelve problemas — los delega dinámicamente a un pool de LLMs (GPT-5, Claude Sonnet 4, Gemini 2.5 Pro). Logra SOTA en GPQA-Diamond y LiveCodeBench superando a cada modelo frontier individual. Ya está productizado como Sakana Fugu con API compatible OpenAI.

Multi-model routing con un modelo pequeño entrenado en 2 H100s — patrón replicable si quieres optimizar costo/calidad en tu backend de AI.

VentureBeat • Sakana AI

Mistral Workflows: orquestación enterprise con Temporal, millones de ejecuciones diarias en producción

Mistral lanzó Workflows en preview público, un motor de orquestación construido sobre Temporal para procesos AI multi-paso con estado. Los workflows se definen en Python combinando modelos, agentes y conectores externos, con el data plane desplegado en el Kubernetes del cliente. ASML, ABANCA y CMA-CGM ya lo usan en producción.

Si necesitas orquestar pipelines AI durables (procesamiento de órdenes, onboarding, reconciliación), esto te ahorra armar tu propio Temporal + LLM glue.

Claude y ecosistema Anthropic

Code with Claude 2026: Dreaming, Multiagent y Outcomes para Managed Agents

En la conferencia Code with Claude (12 mayo), Anthropic anunció tres features para Managed Agents: Dreaming (revisión autónoma de sesiones pasadas para auto-mejora), Multiagent Orchestration (un agente líder delega a sub-agentes especializados en paralelo con filesystem compartido), y Outcomes (rúbricas de éxito para que el agente itere hasta cumplir criterios). También duplicó rate limits de Claude Code y subió límites de API para Opus.

Dreaming + Outcomes es el loop que faltaba para agentes en producción: aprenden entre sesiones y validan su propio output antes de entregarlo.

Claude Code desktop rediseñado: sesiones paralelas, terminal integrado y editor de archivos

Anthropic rediseñó la app de escritorio de Claude Code con un sidebar de sesiones para gestionar múltiples tareas en paralelo, terminal integrado, editor de archivos in-app, visor de diffs optimizado para changesets grandes, y soporte SSH en Mac. El concepto: tú como orquestador de múltiples agentes trabajando simultáneamente.

Ahora puedes tener un refactor, un bug fix y tests corriendo en repos separados al mismo tiempo desde una sola ventana.
