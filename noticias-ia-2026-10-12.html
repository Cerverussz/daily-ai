Aplicaciones profesionales de IA

🔥 Microsoft Execution Containers (MXC) llega a GA: sandbox para agentes AI en Windows, macOS y Linux

Microsoft lanzó la disponibilidad general de MXC, una capa de contención por políticas que limita lo que los agentes AI pueden hacer en el sistema operativo. Soporta contenedores de proceso (Windows/macOS/Linux), de sesión y WSL (Windows 11), con OpenAI Codex, GitHub Copilot, Replit y NVIDIA OpenShell ya integrados.

Si estás construyendo agentes que ejecutan código o acceden al filesystem de tus usuarios, MXC resuelve el sandboxing que antes tenías que implementar tú mismo.

🔥 NVIDIA RTX Spark: laptops con 1 PFLOP de AI y 128GB de memoria unificada desde noviembre

NVIDIA abrió pre-órdenes para laptops RTX Spark con GPU Blackwell + CPU Grace. Acer, ASUS, Dell, HP, Lenovo y MSI fabricarán equipos, y la herramienta NVIDIA PAIR (open-source) salió de beta para distribuir workloads AI entre PCs locales con soporte llama.cpp.

Un petaflop local cambia la ecuación de costos para fine-tuning, inferencia y testing de modelos sin depender de cloud.

Nous Research lanza Hermes Enterprise: agentes AI para workflows corporativos

Nous Research (valorada en $1.5B tras su Serie B de $90M) lanzó la versión enterprise de Hermes con templates pre-construidos para ventas, soporte e integraciones con SAP y Odoo. El modelo base es open-source (MIT) con arquitectura agent-first y memoria persistente entre sesiones.

Un framework de agentes open-source con wrapper enterprise es exactamente lo que necesitas si quieres construir sobre código que puedes auditar sin vendor lock-in.

Innovaciones técnicas con potencial práctico

🔥 Google AISeal: enclave de seguridad para AI on-device en Android

Google anunció AISeal, una arquitectura de enclave basada en Android Virtualization Framework y pKVM que aísla datos personales del contexto AI en almacenamiento encriptado local. MediaTek Dimensity 9600 Pro y Qualcomm Snapdragon ya soportan la arquitectura; AppSearch es la implementación de referencia.

Si desarrollas apps Android que procesan datos sensibles con AI on-device, AISeal te da aislamiento a nivel de hardware sin tener que construir tu propio sandbox.

🔥 Qualcomm en India Mobile Congress: agentes AI on-device como futuro del móvil

En el India Mobile Congress 2026, Qualcomm presentó sus chips Snapdragon 8 Elite Extreme Gen 6 con demos de agentes que completan tareas multi-paso (como armar itinerarios desde un email) procesando todo en el dispositivo. También mostraron un espejo inteligente corriendo modelos open-weight directamente en el NPU.

Los agentes on-device abren un nuevo paradigma para apps móviles: tareas complejas sin latencia de red ni costo de API por request.

Business Today • SammyGuru

Sakana AI presenta MASS: un solo modelo de 27B como solver, optimizador y evaluador

Sakana AI publicó MASS, un método que reutiliza un único modelo open-weights de 27B parámetros para resolver, optimizar workflows y evaluar resultados simultáneamente. Reportan mejoras en MLR-Bench y DSBench frente a pipelines multi-modelo.

Reducir tres modelos a uno baja drásticamente el costo de inferencia en pipelines de agentes — especialmente relevante si self-hosteas.

Claude y ecosistema Anthropic

Claude Haiku 5.5 disponible: el modelo más rápido de Anthropic con thinking adaptativo

Anthropic lanzó Claude Haiku 5.5 el 7 de octubre, completando la familia Claude 5.5. Es el primer Haiku con controles de esfuerzo y thinking adaptativo, a $0.10/M input y $0.50/M output con ventana de 1M tokens.

A ese precio con 1M de contexto, Haiku 5.5 es ideal para clasificación, routing y tareas de subagentes en tu backend sin reventar el presupuesto.

MCP Tunnels en research preview: conecta Claude a servidores MCP privados

Anthropic abrió MCP Tunnels como research preview, permitiendo que Claude acceda a servidores MCP dentro de redes privadas mediante conexión outbound-only (sin abrir puertos en tu firewall). Disponible para planes Enterprise y también vía API con un plugin oficial en el marketplace.

Si tienes APIs internas o bases de datos detrás de un firewall, MCP Tunnels elimina la necesidad de exponer endpoints públicos para que tus agentes AI los consuman.

Models API ahora reporta capacidades de server tools por modelo

Anthropic agregó el campo capabilities.server_tools a la Models API, permitiendo consultar programáticamente qué modelos soportan web search y code execution. También se añadió capabilities.thinking.types.disabled para verificar soporte de thinking.

Si tu producto rutea entre modelos Claude dinámicamente, ahora puedes validar capacidades en runtime en vez de hardcodear una tabla de features.
