🔥 Google mata Gemini CLI y Code Assist para individuales: migración forzada a Antigravity

Desde el 18 de junio, Gemini CLI y las extensiones de Gemini Code Assist dejaron de funcionar para usuarios individuales, Google AI Pro y Ultra. La alternativa es Antigravity CLI (binario agy), closed-source y basado en Go, con un free tier reducido de 1,000 a solo 20 requests/día.

Si tenías scripts, pipelines CI o automatizaciones con gemini, se rompieron ayer — evalúa Claude Code o Cursor como reemplazo antes de migrar a un ecosistema cerrado.

🔥 GitHub Copilot con billing por uso: developers reportan aumentos de costos de 10x a 50x

Desde junio 1, GitHub Copilot usa AI Credits basados en tokens consumidos (1 crédito = $0.01). Los precios base de suscripción no cambiaron, pero developers reportan saltos de $29 a $750/mes y sesiones agénticas individuales que cuestan $38. Un developer vio desaparecer el 82% de su allowance mensual en el primer día.

Si usas Copilot con flujos agénticos intensivos, audita tu consumo ahora — Claude Code con su modelo de suscripción fija puede ser más predecible para tu presupuesto.

🔥 OpenAI completa adquisición de Astral: uv, ruff y ty se integran en Codex

OpenAI cerró la adquisición de Astral, el equipo detrás de uv (package manager), ruff (linter/formatter) y ty (type checker) para Python. Las herramientas se integrarán directamente en Codex, que ya tiene 2M+ usuarios activos semanales. OpenAI se comprometió a mantener los proyectos open-source.

🔥 La economía de los AI coding tools se fractura: suscripción fija vs. pago por token

El mercado de herramientas de coding AI se divide en dos modelos: pago por token (Copilot AI Credits, APIs por uso) vs. suscripción predecible (Cursor Pro a $20/mes, Claude Code en Max). El shock de billing de Copilot está empujando a founders y equipos pequeños a re-evaluar su stack completo de desarrollo.

Para un founder técnico, el riesgo de un modelo por token no es el precio promedio sino la varianza — una sesión de debugging agéntica puede costar más que todo tu mes de herramientas.

US Government ordena a Anthropic suspender Fable 5 y Mythos 5 por control de exportaciones

El 12 de junio, Anthropic desactivó Claude Fable 5 y Mythos 5 globalmente tras una directiva del gobierno de EE.UU. que prohíbe acceso a cualquier nacional extranjero, incluyendo empleados de Anthropic. La razón: se descubrió un método de jailbreak que podía acceder a las capacidades de ciberseguridad de Mythos. Más de 100 expertos en ciberseguridad han pedido levantar la restricción.

Si dependías de Fable 5 en producción, esto es un recordatorio de riesgo regulatorio — diseña tu stack AI con fallback a modelos alternativos (Opus 4.8, Sonnet 4.6) siempre.

Claude Platform on AWS: API nativa de Anthropic con billing e IAM de AWS

Anthropic lanzó Claude Platform on AWS, que trae la API completa de Claude (Messages, Files, Batch, Managed Agents, MCP connectors) a infraestructura gestionada por Anthropic pero con autenticación IAM/SigV4 y billing consolidado de AWS. Es distinto a Bedrock: aquí Anthropic opera el stack de inferencia.

Si ya estás en AWS y quieres acceso a features de Claude que no están en Bedrock (managed agents, code execution), esto elimina la fricción de una segunda cuenta de billing.
