Aplicaciones profesionales de IA

🔥 OpenAI adquiere Ona: ejecución cloud persistente para agentes Codex

OpenAI anunció la adquisición de Ona, plataforma de ejecución cloud segura usada por 2 millones de desarrolladores. La tecnología permitirá que los agentes de Codex trabajen en tareas de horas o días con estado persistente, sin depender de un dispositivo activo.

Si estás evaluando cómo delegar tareas complejas a agentes AI en tu producto, esto confirma que la infraestructura de ejecución persistente es el cuello de botella que todos están resolviendo.

🔥 Xcode 27: coding agéntico con Claude, Gemini y GPT integrados

Apple presentó Xcode 27 con agentes AI que pueden explorar codebases, planificar features, ejecutar tests, interactuar con el simulador y diagnosticar crashes automáticamente. El autocompletado corre on-device en el Neural Engine; los agentes usan modelos de Anthropic, Google y OpenAI con opt-in explícito.

Si desarrollas para iOS/macOS, ahora tienes Claude Code-level de capacidad agente directamente en Xcode, con soporte MCP y Agent Client Protocol para extender con tus propios plugins.

Apple Newsroom • 9to5Mac

Innovaciones técnicas con potencial práctico

🔥 Apple Foundation Models: open source, multimodal y gratis para devs pequeños

Apple anunció que su Foundation Models framework será open source este verano, con soporte multimodal (imágenes + texto) on-device y un nuevo Python SDK. Anthropic y Google ya ofrecen Swift SDKs para llamar Claude y Gemini desde la misma API, y es gratis en Private Cloud Compute para apps con menos de 2M descargas.

Si lanzas una app móvil, puedes integrar AI on-device sin costo de infraestructura y con la misma interfaz Swift para modelos locales o cloud.

Apple Developer • TechResearchOnline

🔥 OpenCode llega a #1 en coding agents: 172K stars, 7.5M devs, open source

OpenCode se posicionó como el agente de coding open source más adoptado del mundo con 172K+ GitHub stars, 900 contribuidores y 7.5M devs activos mensuales. Es provider-agnostic (Claude, Gemini, GPT, modelos locales en la misma sesión) con integración LSP real para types, signatures y diagnósticos en 18+ lenguajes.

Como alternativa gratuita a Claude Code con soporte multi-modelo, vale la pena probarlo si quieres flexibilidad de proveedor sin lock-in.

OpenCode • GitHub

Microsoft Edge: modelo on-device Aion-1.0, traducción local en 145+ idiomas y speech recognition

Microsoft liberó en preview el SLM Aion-1.0-Instruct que corre on-device en Edge, incluyendo máquinas sin GPU dedicada. También lanzó APIs de traducción local (145+ idiomas) y reconocimiento de voz on-device en español, inglés, alemán, italiano, portugués y coreano.

Traducción y speech sin servidor significa cero costo por request y cero dependencia externa para features de internacionalización en tu web app.

Creación de negocios y productos con IA

🔥 Windsurf muere, nace Devin Desktop: Agent Client Protocol abre el mercado de IDEs

Windsurf se transformó en Devin Desktop el 2 de junio, reescribiendo su agente local en Rust (30% más eficiente en tokens). El cambio real: soporta Agent Client Protocol (ACP), un protocolo abierto que permite correr Codex, Claude Agent u OpenCode dentro del mismo editor.

ACP es para IDEs lo que MCP es para herramientas: si estás construyendo un agente AI, soportar ACP te da distribución instantánea en cualquier editor compatible.

Devin Blog • DigitalApplied

🔥 GitHub Copilot billing shock: devs reportan facturas de $180 en día 1

El cambio a billing por uso de GitHub Copilot (1 AI credit = $0.01 USD) entró en vigor el 1 de junio y los reportes de costos disparados no paran. Un dev en plan Pro+ ($39/mes) consumió 8% de sus créditos mensuales en 2 horas; otro estima que su factura subirá de $29 a $750/mes.

Ésta es la señal definitiva para evaluar alternativas como OpenCode (gratis), Claude Code, o modelos locales para tareas de alto volumen.

TechCrunch • Visual Studio Magazine

Claude y ecosistema Anthropic

Claude Fable 5: el modelo Mythos-class llega al público general

Anthropic lanzó Claude Fable 5 el 9 de junio, su modelo más potente de acceso general. Excede a todo modelo previo de Anthropic en software engineering, visión y trabajo autónomo prolongado. Stripe reportó que comprimió meses de ingeniería en días, migrando un codebase de 50M líneas Ruby en un día.

A $10/$50 por millón de tokens (menos de la mitad del precio de Mythos Preview), es el mejor modelo disponible para tareas de coding agente complejas y de larga duración.

Anthropic • TechCrunch

Claude Code: sub-agentes anidados y sandboxes auto-hospedados en beta

Claude Code agregó soporte para sub-agentes anidados (nested sub-agents), mejor selección de modelo/región, y búsqueda de plugins. Paralelamente, Managed Agents ahora soporta sandboxes auto-hospedados (Cloudflare, Daytona, Modal, Vercel) con MCP tunnels en research preview.

Sub-agentes anidados permiten descomponer tareas complejas sin salir de Claude Code, y los sandboxes propios te dan control total sobre dónde corre tu agente.

Releasebot • Anthropic Updates
