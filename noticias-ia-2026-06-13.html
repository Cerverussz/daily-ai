🔥 Xcode 27 integra Claude, Gemini y ChatGPT: coding agéntico multi-modelo en tu IDE

🔥 Inferencia on-device cruza el umbral: sub-20ms en Android con NPUs estándar

Benchmarks de producción muestran que la inferencia AI on-device en móviles ya logra latencia sub-20ms para modelos de computer vision. Claude y ecosistema Anthropic

Claude Code: sub-agentes anidados, “Dreaming” y Opus 4.8 como default

Claude Code subió a Opus 4.8 como modelo por defecto, duplicó límites de rate, y lanzó sub-agentes anidados (agentes que generan sus propios sub-agentes para descomponer tareas). La nueva feature “Dreaming” revisa sesiones pasadas automáticamente para mejorar memoria y detectar patrones recurrentes entre sesiones.

Dreaming convierte a Claude Code de herramienta stateless a un asistente que aprende de tu proyecto — menos repetición de contexto en cada sesión.

🔥 Claude integrado en iOS 27: Apple Foundation Models permite elegir proveedor AI

iOS 27 introduce un protocolo LanguageModel que permite a las apps intercambiar entre Apple Foundation Models, Claude, Gemini u otros proveedores vía Swift Package Manager sin cambiar código de sesión. Tu app iOS puede ahora ofrecer Claude como backend de AI sin manejar API keys del usuario — Apple abstrae la autenticación y el routing por ti.
