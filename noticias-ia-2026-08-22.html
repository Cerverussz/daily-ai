Aplicaciones profesionales de IA

🔥 Slack Code: agentes de coding AI integrados en canales de equipo

Slack lanzó Slack Code el 21 de agosto, un producto que integra agentes de coding (Claude Code, Devin, Copilot, Vercel) directamente en canales dedicados de Slack. El equipo ve la conversación, revisa diffs en tiempo real, da feedback que el agente incorpora, y aprueba antes de hacer merge.

Convierte el coding con agentes de una actividad solitaria en terminal a un flujo de equipo observable — ideal si lideras un equipo pequeño y necesitas visibilidad sin micromanagement.

🔥 Firecrawl Developer Index: 70M+ repos indexados para coding agents

Firecrawl lanzó Developer Index el 20 de agosto, un índice especializado de 70M+ artefactos (READMEs, docs, issues, PRs, OpenAPI specs) con búsqueda semántica y filtros por metadata, actualizado diariamente. Logra 0.63 recall@10 en DevDex, su benchmark abierto de 1,179 queries reales de developers.

Si tu coding agent pierde tiempo buscando docs o issues relevantes, este índice le da contexto preciso de fuentes primarias en lugar de páginas web genéricas.

Cloudflare Kitesurf + x402: browser y pagos autónomos para agentes AI

Cloudflare lanzó Kitesurf, un browser sin Chromium construido en V8 isolates que usa 3-7x menos memoria y CPU, compatible con Puppeteer/Playwright. En paralelo, activó Cloudflare Wallets con el protocolo x402 para que agentes AI paguen por APIs y servicios autónomamente con límites de gasto.

Si estás construyendo agentes que necesitan navegar web o consumir APIs de pago, esta infra elimina dos problemas que antes resolvías a mano: browser headless costoso y pagos machine-to-machine.

🔥 Google Antigravity escapa de su IDE: extensiones para VS Code y JetBrains

Google lanzó extensiones de Antigravity para VS Code, JetBrains, Visual Studio y Zed, permitiendo delegar tareas multi-paso al agente desde un panel lateral sin migrar el proyecto al IDE propio de Antigravity. El agente usa Gemini 3.5 Flash y es gratuito.

Otro competidor serio en tu IDE existente — la guerra de coding agents ahora se pelea dentro de VS Code, no en IDEs propietarios separados.

Gemini 3.7 Flash: coding y agentes con 50% de descuento introductorio

Google lanzó Gemini 3.7 Flash el 13 de agosto con foco en coding, razonamiento y workflows agénticos. Precio introductorio de $0.75/$3.75 por millón de tokens (input/output) hasta diciembre 2026 — la mitad del precio de Gemini 3.6 Flash. Cached input a $0.075/M.

A esos precios con caching, es una opción competitiva para pipelines de alto volumen donde no necesitas el modelo más capaz sino el más eficiente.

CellCog August Rankings: Claude Code #1 en profundidad de coding

Los rankings de agosto de CellCog posicionan a Claude Code primero en pure coding depth (hooks, subagents, dynamic workflows), Codex CLI primero en autonomía cloud, y Cursor primero en flujo in-editor. Meta Muse Code entra como nuevo competidor con subagentes paralelos y worktree isolation.

🔥 GPT-5.6 Luna gratis e ilimitado para chat + precio API caído 80%

OpenAI hizo GPT-5.6 Luna el modelo default para usuarios gratuitos con chats de texto ilimitados y botón Think. En API, Luna bajó a $0.20/M input tokens — una caída del 80% vs precios anteriores. Sol se retunó para Plus/Pro con 68% menos errores factuales vs GPT-5.5.

AI escribe la mitad de los issues en Linear, pero los equipos aún no envían más rápido

Datos de agosto muestran que AI ahora redacta casi la mitad de todos los issues en Linear. Los equipos triplicaron PRs, pero el tiempo total de desarrollo subió en lugar de bajar. Más output no se traduce automáticamente en más velocidad de entrega.

Validación de que automatizar la producción de código sin rediseñar el proceso de review y merge crea un cuello de botella nuevo — antes de añadir más AI, optimiza tu pipeline de integración.

Claude y ecosistema Anthropic

Claude Code: mejoras en sessions cloud, code review y estabilidad

Las últimas versiones de Claude Code mejoran el rendimiento de sesiones cloud en background, fiabilidad de remote control y VS Code, revisión de código, y añaden spellcheck opcional en el prompt. También reducen event-loop stalls y corrigen bugs de permisos y slash commands.

Las mejoras en background sessions y estabilidad hacen que Claude Code sea más viable para tareas autónomas de larga duración como CI fixes o refactors nocturnos.

Releasebot • Gradually.ai

Anthropic activa watermark invisible en toda la salida de Claude (EU AI Act)

Desde el 2 de agosto, Anthropic marca con watermark invisible todo el texto y archivos generados por Claude para cumplir con las reglas de transparencia del EU AI Act. La marca se aplica globalmente, no solo para usuarios europeos.

Si tu producto genera contenido con Claude para usuarios finales, ten en cuenta que ese contenido es ahora detectable como generado por AI — impacta cómo presentas contenido AI-generated en tu plataforma.
