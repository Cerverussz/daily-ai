Aplicaciones profesionales de IA

🔥 Microsoft Scout: agente personal always-on integrado en todo M365

Microsoft lanzó Scout, un agente AI autónomo con identidad Entra propia que monitorea proactivamente Teams, Outlook, OneDrive y SharePoint. Identifica tareas pendientes, surfacea contexto y prepara borradores antes de que lo pidas, incluido en M365 E7 a $99/usuario/mes.

Esto establece el estándar de lo que los usuarios esperan de agentes autónomos — si estás construyendo un SaaS o marketplace, tus usuarios pronto exigirán este nivel de proactividad.

🔥 OpenCode supera 178K estrellas en GitHub: agente de coding open-source se consolida

OpenCode, agente de coding MIT-licensed y model-agnostic (terminal, IDE, desktop), alcanzó 178K estrellas y 7.5M+ devs activos mensuales. Incluye integración LSP con type info real en 18+ lenguajes, modos plan/build, multi-agente, y soporte para 75+ proveedores incluyendo Claude, GPT y Gemini.

Si no quieres vendor lock-in en tu tooling de coding, OpenCode te da un agente clase Cursor/Claude Code que puedes apuntar a cualquier modelo y controlar completamente.

OpenCode • Developer's Digest

Innovaciones técnicas con potencial práctico

🔥 Google I/O 2026: crea apps Android con prompts + Android CLI para agentes AI

Google permite construir apps Android nativas directamente en AI Studio seleccionando “Build an Android app” y escribiendo un prompt, con soporte nativo de Kotlin. El nuevo Android CLI estable habilita a agentes AI para descargar SDKs, ejecutar apps en dispositivos y automatizar builds.

El ciclo de prototipado Android pasa de días a minutos, y el CLI significa que tus agentes de coding pueden ahora construir, testear y deployar apps Android end-to-end.

Google Blog • Google Developers

🔥 Apple abre Foundation Models a todos los devs — tier gratuito para apps pequeñas

En WWDC 2026, Apple expandió su framework Foundation Models a una plataforma híbrida: modelos on-device con input de imagen, integración server-side (Claude y Gemini vía la misma Swift API), y Dynamic Profiles para workflows multi-agente. Devs con menos de 2M descargas de primera vez acceden gratis a Private Cloud Compute.

Si estás construyendo una app iOS, ahora tienes AI on-device + cloud gratis con una sola API Swift — la barrera de costo para devs indie desaparece.

Apple Newsroom • MindStudio

🔥 Gemini Nano 4 + AICore: AI on-device para apps Android sin conexión

Las ML Kit GenAI APIs de Google (actualizadas el 19 de junio) ejecutan Gemini Nano on-device para summarization, proofreading y rewriting sin red. El AICore Developer Preview da acceso anticipado a modelos Gemini Nano 4 con código forward-compatible que se actualiza automáticamente con nuevo hardware.

Para apps Android de marketplace o servicios, AI on-device significa procesamiento de texto instantáneo, cero costos cloud y features que funcionan offline.

Android Developers • Android Developers Blog

OpenAI presenta GPT-5.6 en tres tiers: Sol, Terra, Luna

OpenAI presentó GPT-5.6 con tres niveles: Sol (flagship para problemas complejos), Terra (competitivo con GPT-5.5 a mitad de precio) y Luna (rápido y económico para volumen). La Casa Blanca solicitó release limitado a partners aprobados por el gobierno primero.

La estructura tiered refleja cómo los sistemas en producción necesitan modelos diferentes para tareas diferentes, pero el gating gubernamental genera incertidumbre de acceso para builders independientes.

DeepSeek recorta precios permanentemente: $0.44/M tokens de input

DeepSeek hizo permanente su rebaja del 75% en V4-Pro: $0.44/M input y $0.87/M output, undercut de 5x a GPT-5.5 en input y 17x en output. Lindy AI migró 100% de su tráfico de producción de Claude a DeepSeek por la curva de costos.
