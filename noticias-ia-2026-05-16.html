🔥 Coder Agents: coding autónomo self-hosted y model-agnostic para enterprise

Coder Technologies lanzó en beta sus Agents que corren completamente en infraestructura propia, sin enviar código fuente a terceros. Soportan cualquier modelo (Claude, GPT, Llama) y ejecutan tareas como escribir código, generar tests, analizar repos y abrir PRs via conversación o API.

Para equipos que necesitan agentes de coding pero no pueden enviar su código a la nube, esto elimina el blocker de seguridad sin sacrificar funcionalidad.

GlobeNewsWire • InfoQ

Augment Code lanza Intent: orquestación multi-agente con living specs

Intent es un workspace macOS donde un Coordinator agent divide tareas en especificaciones vivas y las delega a agentes especialistas en paralelo, cada uno con workspace aislado. Las specs se auto-actualizan conforme los agentes completan trabajo.

El patrón “coordinator + specialist agents” con specs como fuente de verdad es lo más cercano a tener un equipo de ingenieros autónomo en tu terminal.

El equipo de seguridad de Google documentó que páginas web maliciosas están inyectando instrucciones ocultas para secuestrar agentes AI con acceso a email, calendarios y sistemas empresariales. Los ataques ya no son teóricos: hay explotación real en producción.

🔥 Claude Code Agent View: dashboard para gestionar múltiples agentes en paralelo

Anthropic lanzó Agent View (Research Preview): un dashboard CLI que muestra todas las sesiones activas de Claude Code en una lista, con estado, última respuesta, y si el agente necesita tu input. Se accede con flecha izquierda o claude agents. Requiere v2.1.139+.

Poder despachar 8 agentes en paralelo y solo intervenir cuando uno se atasca cambia radicalmente la velocidad de desarrollo para tareas grandes — esto es el multiplayer mode que faltaba.

Claude Managed Agents introduce “Dreaming”: auto-mejora entre sesiones

La nueva feature Dreaming permite que los agentes managed revisen sesiones pasadas, extraigan patrones (errores recurrentes, workflows exitosos) y actualicen su memoria para mejorar sin intervención. Harvey (legal AI) reportó 6x mejora en task completion con Dreaming activo.

Si usas agentes managed para tareas repetitivas (onboarding, procesamiento de órdenes), Dreaming convierte cada ejecución en datos de entrenamiento implícito sin que toques nada.
