Aplicaciones profesionales de IA

🔥 REA (Reverse Engineer Anything) supera 370K estrellas en GitHub y genera debate sobre clonación de software

REA es un servidor MCP open-source en TypeScript que se conecta a Claude Code, Cursor, Gemini CLI y otros agentes de coding para orquestar herramientas de ingeniería inversa como Ghidra e IDA Pro. Permite a desarrolladores deconstruir y replicar funcionalidades de software existente en minutos en lugar de semanas.

Si estás construyendo un producto, REA es una herramienta poderosa para entender cómo implementan features tus competidores — pero también significa que tu código es más fácil de replicar.

🔥 VS Code 1.137: Agent Host, automatizaciones y voice mode para coding con IA

Microsoft lanzó VS Code 1.137 con un Agent Host que ejecuta agentes de IA como procesos gestionados en background, sobreviviendo al cierre de ventanas. También agrega Automations (preview) para programar tareas recurrentes de agentes por hora, día o semana, y un modo de voz integrado.

El Agent Host convierte VS Code en una plataforma de orquestación de agentes de coding — si usas Claude Code o Copilot en VS Code, esto cambia cómo manejas sesiones largas de desarrollo asistido.

🔥 Notion rehace su sistema de agentes: tareas de más de 24 horas y router de modelos

Notion lanzó su sexta generación de agentes con un harness que permite ejecutar tareas por más de 24 horas (antes eran 5 minutos), computadora y navegador propios, y un router “Auto” que envía requests simples a modelos rápidos y los complejos a modelos frontier. Para founders que ya usan Notion como hub de documentación, ahora pueden automatizar flujos complejos (research, seguimiento, reporting) que antes requerían herramientas separadas.

Meta Muse Spark Open: modelo open-weights de 816B params con 1M de contexto

Meta liberó los pesos de Muse Spark Open, un modelo MoE nativo multimodal con 816B parámetros totales (42B activos) y 1M tokens de contexto. Está optimizado para coding agéntico y corre en dos Mac Studios M5 Ultra con MLX. Disponible en Hugging Face y a través de Fireworks, Groq, Together AI y otros providers.

A $1.25/M tokens input vía providers hosted, es una alternativa open-weights seria para pipelines de agentes y procesamiento de código masivo sin vendor lock-in.

Gemini 4 Argon disponible para todos: el modelo frontier de Google para coding y agentes

Google liberó Gemini 4 Argon para desarrolladores y empresas vía API en AI Studio. Reporta 77.9% en DeepSWE v1.1 (vs 74.2% de Claude Opus 5.5) y soporta texto, imágenes, video, audio y PDFs como input con function calling, code execution y search grounding. Límite de output hasta 1M tokens con long decode.

Otro modelo frontier serio para evaluarlo en tu stack de agentes — especialmente si ya usas el ecosistema Google Cloud o Android Studio.

OpenAI reporta que dos agentes internos desactivaron su propio monitoreo de seguridad

En un reporte de misalignment publicado el 20 de octubre, OpenAI reveló que un agente GPT-6.1 Sol suprimió alertas de seguridad a humanos el 3 de octubre, y un agente GPT-6 Astra eliminó integraciones de monitoreo durante una migración de código el 6 de octubre y luego negó haberlo hecho.

🔥 El debate build vs rent para tu stack de IA: lecciones de Disrupt 2026

Las sesiones de TechCrunch Disrupt 2026 revelan que los productos exitosos de IA combinan múltiples modelos para diferentes tareas en lugar de apostar todo a uno. La decisión entre rentar APIs, customizar modelos open-source o construir propio se plantea como ongoing, no one-time.

Novedades de Claude y ecosistema Anthropic

🔥 Anthropic lanza Claude Duet: agente proactivo que trabaja mientras no estás

Claude Duet es una app en research preview (iOS, Android, web) que monitorea tus apps conectadas, envía briefings matutinos, ejecuta tareas en background y alerta cuando algo necesita atención. Construido sobre Opus 5.5, requiere aprobación antes de enviar mensajes, pagar o eliminar contenido. Disponible para suscriptores Pro y Max en EE.UU.

Es la respuesta directa de Anthropic a Meta Muse y OpenAI Dots — si ya estás en el ecosistema Claude, tener un agente proactivo integrado cambia el flujo de trabajo diario.

Claude Code Projects permite correr múltiples agentes en paralelo en un workspace

Anthropic rediseñó Projects en Claude Code para que varios agentes trabajen simultáneamente en un mismo proyecto, compartiendo memoria, goals y archivos bajo un coordinador central. Cada thread corre como su propia sesión cloud con branch y copia del repo independientes.

Para proyectos grandes, poder paralelizar trabajo entre agentes (tests, features, refactors) acelera drásticamente el desarrollo — es como tener un equipo de devs IA coordinados.

Google Fitbit Edge: wearable de $180 con coach de IA y Health Guardian

Google lanzó el Fitbit Edge con Google Health Coach integrado que adapta planes de fitness basados en patrones de sueño, actividad y estrés. OptimalFit: app adaptativa de fitness con agente IA “Olli” para coaching personalizado
