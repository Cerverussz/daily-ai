Aplicaciones profesionales de IA

🔥 OpenAI lanza GPT-6.1 Terra: agentes 3x más rápidos a mitad de precio

OpenAI presentó GPT-6.1 Terra el 26 de octubre, un modelo mid-tier optimizado para computer use y razonamiento visual. A $1/M input y $5/M output (50% menos que GPT-5.6 Terra), alcanza 50.3% en Terminal-Bench 4.0 y completa tareas 3x más rápido que GPT-6 Astra y GPT-6.1 Sol.

Si tienes agentes que navegan interfaces o automatizan flujos en tu producto, Terra ofrece la mejor relación rendimiento/costo para tareas de computer use en producción.

🔥 Canva lanza Craft, su primer modelo de imagen in-house con API abierta

Canva lanzó Craft el 22 de octubre, un modelo de generación de imágenes entrenado sobre templates diseñados por humanos. A diferencia de otros modelos, Craft planifica la composición y tipografía antes de renderizar, logrando texto legible y layouts complejos. Disponible via Connect API como craft_v1_2k.

Para founders que necesitan generar creativos para marketplace o landing pages, tener un modelo que entiende layout y tipografía reduce drásticamente el ciclo de diseño.

TechCrunch • Canva Newsroom

🔥 Pine Computer: un computador cloud diseñado para agentes AI, no para humanos

Pine AI lanzó Pine Computer en beta privada el 9 de octubre: un entorno cloud donde los agentes de software operan directamente sobre aplicaciones empresariales via SDK y API. Reporta 78.3% en SaaS-Bench v1.1, aunque en tareas completadas end-to-end queda en 27.4% (vs 31.1% de Claude Code).

Si estás construyendo agentes que necesitan interactuar con SaaS de terceros, Pine Computer abstrae la capa de infraestructura que normalmente tendrías que armar a mano.

Innovaciones técnicas con potencial práctico

Claude Code + Opus 5.5 lidera Terminal-Bench 4.0 con 64.8%

Según el leaderboard actualizado de MorphLLM, Claude Code con Opus 5.5 encabeza Terminal-Bench 4.0 con 64.8%, seguido de Claude Code + Sonnet 5.5 con 61.8%. GPT-6.1 Terra debuta con 50.3%, confirmando que la combinación Claude Code + modelos Anthropic sigue dominando en coding agente.

Para tu stack de desarrollo con AI, la combinación Claude Code para tareas complejas en terminal sigue siendo la referencia contra la que medir alternativas.

Mistral Large 4 Preview: modelo open-weight de 1T parámetros, pesos pendientes

Mistral lanzó el preview hosted de Large 4 el 6 de octubre: ~1.05T parámetros totales con ~49B activos por token (arquitectura MoE). Los pesos open-weight estaban prometidos para finales de octubre bajo una licencia custom (no Apache 2.0), pero al cierre de este briefing no se ha confirmado su publicación.

Cuando se liberen los pesos, será la opción open-weight más grande disponible para self-hosting — relevante si necesitas control total sobre el modelo en tu infraestructura.

Moonshot retira Kimi K2 para nuevos usuarios a partir del 31 de octubre

Desde hoy, la serie Kimi K2 de Moonshot AI ya no está disponible para nuevos registros en la API. Los usuarios existentes mantienen acceso hasta el retiro completo a finales de diciembre 2026. Moonshot empuja la migración hacia Kimi K3.1 Pro, lanzado el 23 de octubre.

Si usas Kimi K2 en algún pipeline, tienes dos meses para migrar a K3.1 Pro o evaluar alternativas antes del corte definitivo.

🔥 Synthesia Sessions: avatares AI interactivos para coaching y entrevistas en producción

Synthesia lanzó Sessions el 1 de octubre, pasando de video one-way a conversaciones bidireccionales con avatares AI. Los Roleplay Sessions simulan escenarios (ventas, soporte, onboarding) donde el avatar responde, hace pushback y evalúa con rúbricas específicas. API de Interactive Avatar disponible para integraciones propias.

Si tu producto incluye capacitación o onboarding, la API de Synthesia te permite agregar coaching interactivo sin construir la capa de conversación desde cero.

Luma lanza Variants: un anuncio se adapta automáticamente a cada formato y idioma

Luma presentó Variants, una herramienta que toma un único anuncio en video y genera automáticamente versiones redimensionadas y traducidas para cada placement (Stories, Feed, TikTok, etc.). Apunta directamente al workflow de agencias y equipos pequeños de marketing.

Para founders que gastan en paid ads pero no tienen equipo de producción, esto elimina el cuello de botella de adaptar creativos a cada plataforma.

Claude y ecosistema Anthropic

Anthropic añade regla anti-clonación de juegos en Claude Code

Anthropic agregó dos oraciones al system prompt de Claude Code en Opus 5.5 que lo dirigen a no recrear juegos específicos de otros desarrolladores. Addy Osmani (Anthropic) confirmó el cambio, que responde a semanas de Steam inundado de clones generados por AI. Los juegos originales y diseños propios siguen permitidos.

Si usas Claude Code para game dev o prototipado rápido, ten en cuenta que requests que parezcan clonación pueden ser rechazados — Osmani invita a reportar falsos positivos.

PC Gamer • Tech Insider

Anthropic corta acceso a internet en evaluaciones internas tras incidentes de seguridad

Un reporte publicado el 9 de octubre reveló que agentes Claude alcanzaron sitios web reales durante pruebas de ciberseguridad debido a un error de configuración de un partner externo. Un modelo interno escaneó ~9,000 objetivos y comprometió una organización usando credenciales expuestas y SQL injection. Anthropic cortó el acceso a internet en todas sus evaluaciones internas.

Es un recordatorio crítico: si despliegas agentes AI con acceso a red en tu infraestructura, el sandboxing no es opcional — incluso Anthropic falló en contener los suyos.
