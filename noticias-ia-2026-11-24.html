Aplicaciones profesionales de IA

🔥 Anthropic lanza Claude Ship: agentes AI que revisan, reparan y aprueban código

Claude Ship es una nueva suite de agentes que maneja todo lo que pasa después de escribir código: review automatizado de PRs, corrección de bugs detectados y aprobación bajo reglas definidas por el equipo. Disponible para repositorios GitHub en planes Team y Enterprise.

Si ya usas Claude Code para escribir, Ship cierra el loop: tu pipeline de PR puede correr sin intervención humana para cambios rutinarios.

🔥 CodeFleet: gestiona Claude Code, Codex y Grok en paralelo desde un solo escritorio

App de escritorio que ejecuta múltiples agentes de coding (Claude Code, OpenAI Codex, Grok, OpenCode) simultáneamente, cada uno en su propio git worktree aislado. Routing inteligente que asigna el modelo óptimo por tarea. Gratuita, sin cuenta requerida.

Para founders técnicos que ya usan varios AI coding tools, esto elimina el context-switching y te deja comparar outputs en tiempo real.

Google Gemini 4 Neon: modelo mid-tier a $3/$15 por M tokens con 1M de contexto

Google lanzó Gemini 4 Neon el 18 de noviembre, posicionado entre Carbon (tareas complejas) y Hydrogen (uso diario). Ocupa el #3 en el Artificial Analysis Intelligence Index con score de 61. Disponible en Gemini API, AI Studio y Google Antigravity.

Google Blog • 9to5Google

OpenAI GPT-6.2 Sol y Astra: nuevos modelos llegan a ChatGPT y API

OpenAI lanzó GPT-6.2 Astra (flagship para proyectos complejos) y Sol (eficiente para trabajo diario) el 17 de noviembre. Sol alcanza casi el mismo rendimiento que Astra a un quinto del costo ($2/$10 por M tokens) con 1.05M tokens de contexto.

Sol a $2/M input es el modelo frontier más barato del mercado ahora mismo; ideal para pipelines de alto volumen donde antes usabas modelos open-source.

🔥 PrismML Ternary Bonsai 2.5 27B: coding agéntico open-source para correr local

PrismML lanzó Ternary Bonsai 2.5, modelo de 27B parámetros bajo Apache 2.0 optimizado para agentic coding, razonamiento multimodal y tool-use de largo horizonte. Con ~8.5 GB de pesos, corre en hardware consumer manteniendo 98% del rendimiento del modelo base.

Un modelo de coding que corre en tu laptop sin API keys es game-changer para prototipar offline o en contextos donde no puedes enviar código a la nube.

🔥 GitHub amplía Copilot Fusion y añade GPT-6.2 a Copilot

GitHub integró los modelos GPT-6.2 Astra y Sol en Copilot y amplió la disponibilidad de Copilot Fusion, que lidera Terminal-Bench 4.1 con 71.2%. Fusion combina múltiples modelos para resolver tareas de coding más complejas que un solo modelo.

Copilot Fusion superando a Claude Code en benchmarks de terminal significa que la competencia de AI coding tools está más reñida que nunca; prueba ambos antes de elegir.
