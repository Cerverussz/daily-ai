Claude y ecosistema Anthropic

🔥 Claude Opus 4.8 con Dynamic Workflows: migraciones de codebase completas en una sola sesión

Anthropic lanzó Opus 4.8 el 28 de mayo, con 69.2% en SWE-Bench Pro (vs 64.3% de Opus 4.7 y 58.6% de GPT-5.5). La novedad principal son los Dynamic Workflows en Claude Code: el modelo escribe sus propios scripts de orquestación y lanza hasta 1,000 subagentes en paralelo para ejecutar migraciones, refactors o tareas masivas de codebase de principio a fin.

Si tienes una migración pendiente de cientos de archivos o un refactor cross-codebase, ahora puedes lanzarlo en una sola sesión en vez de hacerlo archivo por archivo.

Opus 4.8 Fast Mode 3x más barato + controles de esfuerzo para todos

El Fast Mode de Opus 4.8 (2.5x la velocidad normal) cuesta ahora $10/$50 por millón de tokens input/output, tres veces menos que en modelos anteriores. Además, claude.ai y Cowork añaden un control de esfuerzo junto al selector de modelo: sube para razonamiento profundo, baja para respuestas rápidas.

El fast mode barato hace viable usar Opus para tareas de alto volumen donde antes solo podías justificar Sonnet o Haiku.

The New Stack • 9to5Mac

Claude Managed Agents: sandboxes self-hosted y MCP tunnels en beta pública

Anthropic lanzó self-hosted sandboxes (beta pública) que permiten ejecutar tool calls de agentes en tu propia infra o en Cloudflare/Daytona/Modal/Vercel, y MCP tunnels (research preview) para conectar agentes a servidores MCP privados sin exponerlos a internet. La orquestación sigue en Anthropic, pero la ejecución queda dentro de tu perímetro de seguridad.

Si estás construyendo agentes que tocan datos sensibles de usuarios o inventario, esto elimina el blocker de seguridad sin tener que montar tu propia orquestación.

Innovaciones técnicas con potencial práctico

🔥 GitHub Copilot cambia a facturación por uso el 1 de junio: lo que necesitas saber

Desde el 1 de junio, todos los planes de Copilot migran de requests a AI Credits basados en consumo de tokens ($0.01/crédito). Pro ($10/mes) incluye 1,000 créditos, Pro+ ($39/mes) incluye 3,900. Code completions y Next Edit suggestions siguen incluidas sin costo. Los excedentes se cobran a tarifas de API publicadas.

Revisa tu consumo real esta semana: si usas modelos premium frecuentemente, tu factura podría subir significativamente respecto al flat rate anterior.

GitHub Blog • GitHub Docs

🔥 Android AppFunctions: tu app como servidor MCP on-device para agentes del sistema

Anunciado en Google I/O, Android AppFunctions permite que cualquier app actúe como servidor MCP on-device, exponiendo sus herramientas, servicios y datos al sistema y a agentes locales. Esto convierte a Android en un "sistema de inteligencia" donde los agentes del OS pueden interactuar con apps de terceros sin APIs cloud.

Si desarrollas apps Android, implementar AppFunctions es cómo haces que tu app sea descubrible y accionable por los agentes de IA que Google está integrando en el sistema operativo.
