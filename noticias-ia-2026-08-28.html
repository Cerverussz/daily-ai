🔥 Salesforce y Anthropic lanzan Claudeforce: Claude como AI CRO con 37 skills de ventas

Forcepoint demuestra prompt injection operacional en emails con texto invisible

Forcepoint X-Labs documentó ataques reales de prompt injection donde instrucciones ocultas en emails (CSS zero-font, texto white-on-white) manipulan resumidores AI para cambiar fechas de facturas y omitir nombres. En 10 de 10 intentos, el LLM produjo un resumen manipulado.

Si tu producto procesa contenido de terceros con LLMs (emails, docs, scraping), esto ya no es teórico — necesitas sanitización del DOM antes de pasar contenido al modelo.

Claude y ecosistema Anthropic

🔥 Claude Code: cross-session messaging, restricted mode y auto mode por defecto

Claude Code v2.1.224 introdujo cross-session messaging: sesiones separadas en diferentes terminales pueden descubrirse y pasarse decisiones o hallazgos automáticamente. También se agregó restricted mode para control granular, usage credits para Enterprise, y auto mode como permission mode por defecto.

Cross-session messaging convierte a Claude Code en un sistema multi-agente real — puedes tener un agente haciendo refactor mientras otro corre tests, y se coordinan solos.

Anthropic activa watermarking global en texto de Claude para cumplir EU AI Act

Desde el 2 de agosto, todos los modelos nuevos de Claude incluyen marcas de agua invisibles en texto generado, cumpliendo el Artículo 50 del EU AI Act. La marca sobrevive copy-paste y se aplica globalmente, no solo en Europa. Anthropic publicará herramientas de detección.

Si usas Claude en producción para generar contenido visible al usuario, necesitas saber que ahora lleva watermark — relevante para compliance y para cómo presentas contenido AI-generated.
