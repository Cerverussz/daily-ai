🔥 GitHub Copilot cambia a facturación por tokens: adiós tarifa plana

Desde el 1 de junio, GitHub Copilot migra de suscripción fija a un sistema de GitHub AI Credits basado en consumo de tokens. Las autocompletaciones y Next Edit Suggestions siguen ilimitadas, pero chat, agentes, CLI, Spaces y Spark ahora descuentan créditos (1 crédito = $0.01 USD). Usuarios reportan que facturas de $29/mes podrían escalar a $750/mes con uso intensivo de agentes.

Si usas Copilot con agentes en tu flujo diario, necesitas auditar tu consumo real de tokens hoy o considerar alternativas como Claude Code o Cursor.

Sysdig documenta el primer ciberataque autónomo con agente LLM en producción

El 10 de mayo, Sysdig observó un agente LLM que explotó CVE-2026-39987 en un notebook marimo, extrajo credenciales cloud, pivotó por AWS Secrets Manager, abrió sesiones SSH paralelas y exfiltró una base de datos PostgreSQL completa en menos de una hora sin intervención humana. El agente improvisó el dump sin conocer el schema previo, razonando desde conocimiento general.

Esto cambia el modelo de amenazas para cualquier servicio expuesto a internet: los atacantes con LLMs ya no necesitan expertise técnico profundo para cadenas de ataque complejas.

🔥 Claude Opus 4.8 + Dynamic Workflows: hasta 1,000 subagentes en paralelo

Anthropic lanzó Claude Opus 4.8 (28 de mayo) junto con Dynamic Workflows en Claude Code: un sistema de orquestación que genera scripts JavaScript para coordinar hasta 1,000 subagentes (16 concurrentes) con verificación adversarial integrada. Opus 4.8 mejora coding agéntico de 64.3% a 69.2%, es 4x menos propenso a dejar pasar bugs, y el modo Fast es 3x más barato que en modelos anteriores.

Con ultracode activado, tareas que antes tomaban un sprint completo ahora se resuelven en horas con orquestación automática de agentes.

🔥 Bun portado de Zig a Rust en 11 días: 750K líneas con Dynamic Workflows

Jarred Sumner, creador de Bun, usó Dynamic Workflows de Claude Code para portar el runtime de Zig a Rust: 750,000 líneas, 11 días desde el primer commit al merge, con 99.8% del test suite pasando. Los workflows mapearon lifetimes, escribieron cada .rs como port idéntico del .zig, y un loop de fix automatizó hasta que build y tests quedaron limpios.

Es el caso más concreto de que AI coding agents ya manejan refactors masivos en producción real, no solo demos.

🔥 Microsoft Build 2026: Windows Local AI Runtime con modelos on-device para NPU

Microsoft abre Build 2026 (2-3 de junio) con Windows Local AI: un runtime a nivel de sistema que permite ejecutar agentes AI directamente en NPUs de PCs Copilot+ (Snapdragon X Elite, Intel Lunar Lake, AMD XDNA). Incluye modelos como Phi-4-mini-silicon (2B), Phi-4-vision (7B) y un modelo speech-to-text de 300M, accesibles via APIs para apps Win32, UWP y WinUI 3 sin conexión a cloud.

Si desarrollas para desktop o estás evaluando edge AI, esto abre una plataforma de distribución masiva con modelos pre-instalados y fine-tuning via LoRA empaquetable en la Microsoft Store.

🔥 Anthropic divide facturación el 15 de junio: Agent SDK tendrá pool de créditos separado

A partir del 15 de junio, el uso programático de Claude (Agent SDK, claude -p, GitHub Actions, apps third-party como Zed) se moverá a un pool de créditos independiente facturado a precios de API. Los créditos mensuales son: $20 (Pro), $100 (Max 5x), $200 (Max 20x). Las suscripciones previamente subsidiaban uso de agentes a 15-30x menos que API.

Si tu workflow depende de herramientas third-party con Claude (Zed, scripts con claude -p), calcula tu consumo real ya: el aumento de costo puede ser significativo.
