GitHub Copilot migra a billing por uso el 1 de junio: lo que cambia

GitHub anunció que todos los planes de Copilot migran a AI Credits basados en consumo de tokens el 1 de junio. Code completions y Next Edit Suggestions siguen incluidos sin costo adicional, pero features agénticas (workflows, code review) consumirán créditos. Usar Claude como modelo agota créditos más rápido que Gemini.

Si usas Copilot con Claude como modelo, calcula tu consumo real antes del 1 de junio — heavy users podrían necesitar saltar de Pro ($10) a Pro+ ($39) o considerar Claude Code directamente.

GitHub Blog • Visual Studio Magazine

Google detecta primer zero-day creado con AI: hackers usaron OpenClaw para exploit masivo

Google Threat Intelligence confirmó que un grupo criminal usó modelos AI y el framework agéntico OpenClaw para descubrir y explotar una vulnerabilidad zero-day que bypasea 2FA en una herramienta de administración web. Google cree haber frustrado el ataque masivo planeado antes de su despliegue.

El primer zero-day confirmado creado con AI marca un punto de inflexión — si expones paneles admin, revisa tu 2FA y asume que los atacantes ya usan agentes AI para encontrar vulnerabilidades.

Claude y ecosistema Anthropic

🔥 Claude Managed Agents: dreaming, outcomes y orquestación multiagente

Anthropic lanzó tres capacidades para Managed Agents: Dreaming (revisa sesiones pasadas para extraer patrones y auto-mejorar), Outcomes (rubrics de éxito con grader independiente que evalúa y pide correcciones), y orquestación multiagente (un agente líder delega a especialistas con su propio modelo y tools). Harvey reporta 6x mejora en completion rates con dreaming.

Dreaming convierte a los agentes en sistemas que aprenden entre sesiones sin fine-tuning — si construyes agentes para tareas repetitivas (onboarding, procesamiento de órdenes), esto cambia el juego.

Anthropic Blog • 9to5Mac

Anthropic firma con SpaceX: 300MW y 220K GPUs de capacidad adicional

Anthropic firmó un acuerdo para usar toda la capacidad compute del data center Colossus 1 de SpaceX: más de 300 megawatts y 220,000+ GPUs NVIDIA disponibles dentro del mes. La capacidad adicional beneficiará directamente a suscriptores de Claude Pro y Claude Max.

Más capacidad = menos rate limits y throttling para usuarios Pro/Max, justo cuando los agentes de larga duración empiezan a consumir compute serio.
