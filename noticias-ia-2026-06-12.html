Innovaciones técnicas con potencial práctico

🔥 Apple lanza Core AI: framework nativo para modelos on-device en iOS/macOS

En WWDC 2026 (sesiones finales el 12 de junio), Apple presentó Core AI, un framework para ejecutar modelos custom on-device con compilación ahead-of-time, herramientas Python para convertir PyTorch a Apple Silicon, y API Swift nativa. Incluye modelos open-source optimizados (Qwen, Mistral, SAM3) y acceso gratuito a Foundation Models en Private Cloud Compute para devs con menos de 2M descargas.

Si desarrollas para iOS, Core AI es la vía oficial para AI on-device sin APIs cloud—latencia cero, privacidad por defecto, y gratis para indie devs.

Apple Developer • MacRumors
