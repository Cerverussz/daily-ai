Aplicaciones profesionales de IA

🔥 OpenAI lanza Agents API en beta pública: la infra de Codex para todos

OpenAI liberó su Agents API el 10 de septiembre, exponiendo la misma infraestructura que potencia Codex. Gestiona sesiones de agentes de larga duración, coordinación de herramientas vía MCP, orquestación de sub-agentes, y ejecución en sandboxes hosted o en entornos propios (Cloudflare, Vercel, E2B, Modal, DigitalOcean), sin costo adicional por API — solo pagas modelo y herramientas.

Es la alternativa más production-ready para orquestación de agentes sin armar tu propia capa de sesión y tools desde cero.

Cisco despliega agentes AI personalizados para 90,000 empleados

Cisco expandió su programa “MyAgent” a toda su fuerza laboral global. Cada agente usa el rol, contexto de equipo y actividad reciente del empleado para surfacear información relevante y automatizar tareas rutinarias.

Es uno de los despliegues enterprise más grandes de agentes AI role-specific — valida el modelo de agentes contextuales como herramienta real de productividad, no como piloto.

🔥 Apple presenta iPhone 18 Pro con A20 Pro: AI on-device se duplica

Apple anunció el iPhone 18 Pro con el chip A20 Pro en proceso de 2nm. Incluye un Neural Engine de 32 cores (doble vs A19 Pro), 50% más ancho de banda de memoria, soporte para FP8, y GPU 40% más rápida.

Duplicar el compute de inferencia on-device abre nuevas categorías de features AI que antes requerían cloud — más privacidad, menos latencia, y cero costo por request.

Apple Newsroom • MacRumors

🔥 Android AppFunctions: tu app como servidor MCP para agentes AI

La API AppFunctions de Google (librería Jetpack, ahora en preview experimental) permite que apps Android expongan sus capacidades como servidores MCP on-device. Asistentes como Gemini pueden invocar acciones de tu app directamente, con permisos estructurados y controles de seguridad.

Si desarrollas apps Android, esta es la nueva superficie de integración: las apps que expongan AppFunctions serán descubribles y accionables por agentes AI; las que no, serán invisibles.

Android Developers • Google I/O ’26 Blog

🔥 GitHub Copilot Workspace añade coordinación multi-agente

Copilot Workspace ahora soporta múltiples agentes especializados trabajando simultáneamente en distintas partes del codebase, con agentes separados para implementación, testing y documentación coordinados vía contexto compartido.

Multi-agente dentro del IDE compite directamente con el modelo agéntico de Claude Code — como dev solo o en equipo pequeño, las opciones para manejar codebases complejas se multiplican.

🔥 Mireye (YC S26): infraestructura de location intelligence para agentes AI

Mireye, del batch Summer 2026 de Y Combinator, provee infraestructura de ubicación para agentes AI que toman decisiones sobre lugares físicos en EE.UU. Indexa 366 campos por ubicación y ya se usa en screening de riesgo para seguros, proptech y selección de almacenes para robótica.

Ejemplo concreto de infra para la economía de agentes — si construyes marketplaces o features location-aware, este es el tipo de capa de datos estructurados que los agentes necesitan para operar en el mundo físico.

California firma Adam’s Law: reglas estrictas para chatbots AI con menores

El gobernador Newsom firmó la SB 1119 el 10 de septiembre, obligando a operadores de chatbots AI a detectar ideación suicida en menores, notificar a padres, mantener protocolos de crisis, y pasar auditorías independientes anuales. California es el primer estado con estos requisitos.

Si construyes cualquier producto AI consumer-facing que pueda ser usado por menores, esta ley crea obligaciones concretas de compliance que probablemente se replicarán en otros estados.

Claude Code lanzó una actualización que incluye evaluaciones de plugins, cambio de estilo de output, controles avanzados de workflows y telemetría, y numerosas mejoras de fiabilidad, terminal, prompt-cache y sesión. Los endpoints de user-management de la Admin API para Claude Enterprise salieron de beta.

Anthropic publica 4º informe de amenazas: sistemas multi-agente usados en ciberataques

Anthropic reveló 8 meses de usos maliciosos disrupted de Claude (dic 2025 – ago 2026) en 7 áreas. Hallazgo clave: sistemas multi-agente se usaron para ejecutar partes de ciberataques autónomamente. La mayor campaña de destilación fue atribuida a Alibaba (151M+ intercambios desde 3,500 cuentas fraudulentas destilando Opus 4.6/4.7).

Los hallazgos de destilación y ciberataques autónomos son un wake-up call — el robo de modelos y el uso adversarial son riesgos operacionales reales para cualquiera que construya sobre APIs de AI.

Sam Altman abierto a frenar el desarrollo de AI de frontera

En una reunión interna el 11 de septiembre, Altman dijo a empleados de OpenAI que la compañía está abierta a desacelerar el desarrollo de AI de frontera, esperando que otros labs sigan. Esto tras una brecha de contención y una pausa de dos semanas en entrenamiento a mediados de 2026.

Una posible desaceleración coordinada de la industria afectaría directamente el ritmo de nuevos modelos, capacidades de API y la dinámica competitiva sobre la que los founders técnicos construyen.
