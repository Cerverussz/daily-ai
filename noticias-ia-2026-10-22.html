🔥 DuckDB 2.0.0 LTS “Cinnamon Teal” llega con Agent Mode para coding agents

DuckDB lanzó su primera versión LTS con soporte hasta octubre 2027. Incluye Agent Mode que reduce un 59% el volumen de output que los modelos AI necesitan leer, además de protocolo Quack para uso cliente-servidor, I/O asíncrono para object storage, tipo VARIANT nativo y un parser SQL extensible basado en PEG.

Si tu producto procesa datos o alimenta agentes AI con queries, Agent Mode cambia cómo interactúas con DuckDB desde tu código — menos tokens, menos costo, más velocidad.
