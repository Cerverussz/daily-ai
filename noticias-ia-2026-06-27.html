🔥 Anthropic lanza Workload Identity Federation: API keys estáticas ahora son opcionales

WIF ya está GA en la Claude Platform. Reemplaza las API keys sk-ant-... con credenciales OIDC de corta duración emitidas por tu identity provider: AWS IAM, GCP, GitHub Actions, Kubernetes, Azure Entra ID u Okta. Las API keys tradicionales siguen funcionando para migración gradual.
