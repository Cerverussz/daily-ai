Aplicaciones profesionales de IA

🔥 NVIDIA y Microsoft reinventan Windows para IA personal: RTX Spark y contenedores MXC

En un evento conjunto en San Francisco, Jensen Huang y Satya Nadella presentaron RTX Spark — laptops y desktops con GPU Blackwell + CPU Grace, hasta 128GB de memoria unificada y 1 petaflop de rendimiento AI. Microsoft lanzó MXC (Microsoft Execution Containers) en GA: infraestructura a nivel de OS para que agentes AI corran en segundo plano con seguridad y gobernanza integradas.

Esto cambia la ecuación costo vs. privacidad para cualquier producto que procese datos sensibles: modelos locales con capacidad real, no demos.

🔥 Pwn2Own Ireland: hackean OpenAI Codex y LiteLLM con zero-days — alerta para devs

En la nueva categoría de infraestructura AI de Pwn2Own Ireland 2026, investigadores explotaron 98 zero-days en 3 días ($1.2M+ en premios). Ikotas Labs comprometió OpenAI Codex con una sola inyección de argumentos en comandos git ($40K), y LiteLLM fue vulnerado dos veces mediante validación de input deficiente + inyección de código.

Si usas AI coding agents o gateways LLM en producción, estos exploits demuestran que la superficie de ataque es real y necesitas auditar cómo pasan argumentos a herramientas externas.

Innovaciones técnicas con potencial práctico

🔥 OpenAI lanza Decisions API en beta pública sobre GPT-6 Luna

La Decisions API sale de limited preview y está disponible para todos los developers. Retorna respuestas tipadas: probabilidades (0-1), selección entre opciones con scores de confianza, o puntuación en escalas ordenadas — hasta 200 preguntas por request. Input a $0.10/M tokens, output gratis, con Zero Data Retention y HIPAA.

Un endpoint dedicado a decisiones estructuradas es exactamente lo que necesitas para moderar contenido, clasificar tickets o hacer scoring en tu marketplace sin parsear texto libre.

Mistral Large 4 en preview pública: open-weight con 1T parámetros

Mistral abrió la preview pública de Large 4 el 6 de octubre: modelo MoE de 1.05T parámetros totales (49B activos), con encoder de visión de 1.6B, soporte para 160+ idiomas y contexto de hasta 1M tokens. Los pesos open-weight se publicarán antes de fin de octubre.

Otro modelo frontier open-weight con multimodalidad nativa; ideal para self-hosting si necesitas control total de datos en tu backend.

Claude y ecosistema Anthropic

🔥 Claude Haiku 5.5 lanzado: 75% más barato con 1M tokens de contexto

Anthropic lanzó Haiku 5.5 el 7 de octubre: $0.10/$0.50 por millón de tokens (prompts <100K), contexto de 1M tokens, hasta 128K de output, y thinking adaptativo con parámetro de esfuerzo. Disponible en Claude API, Amazon Bedrock, Google Cloud y Microsoft Foundry. También redujeron el precio de cache-read para Sonnet 5.5 a la mitad.

A ese precio, Haiku 5.5 es el modelo ideal para subagentes de alto volumen, clasificación y summarization en tu pipeline de producción.

Anthropic añade créditos API mensuales a planes Max y Team

Los planes Max y Team ahora incluyen créditos mensuales de API para construir y ejecutar apps y agentes propios en la Claude Platform. Además, los MCP tunnels migraron de la Admin API a la Claude API (/v1/tunnels), y el Models API ahora reporta si un modelo soporta thinking.

Créditos incluidos baja la barrera para prototipar rápido contra la API sin gestionar billing separado desde el día uno.

Claude Code: plugins del marketplace y mejoras de estabilidad

Claude Code actualizó Haiku 5.5 como modelo default, añadió el flag --marketplace para instalar plugins, y una variable de entorno para configurar retry en errores 529. También corrigieron un memory leak en conexiones HTTP MCP.

El marketplace de plugins abre la puerta a extender Claude Code con herramientas de terceros sin configurar MCP servers manualmente.
