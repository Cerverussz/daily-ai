Aplicaciones profesionales de IA

🔥 Meta libera Muse Spark Open: modelo open-weight de 816B parámetros con 1M de contexto

Meta lanzó los pesos de Muse Spark Open el 15 de octubre: un modelo MoE de 816B parámetros totales (42B activos por token) con ventana de 1M tokens, diseñado para coding y tareas agénticas. Acepta texto, imagen, video y audio, y corre en dos Mac Studios M5 Ultra con 512GB cada una.

Es el open-weight más capaz de EE.UU. para agentes autónomos — si construyes pipelines de procesamiento masivo o agentes en tu backend, ahora tienes una alternativa self-hosted seria.

Microsoft completa pre-entrenamiento de MAI-Base-2: 2.8T parámetros con visión nativa

Microsoft anunció el 16 de octubre que terminó el pre-entrenamiento de MAI-Base-2, un modelo MoE de 2.8 trillones de parámetros (80B activos) entrenado en 50T tokens con visión nativa sin encoder. Fue entrenado en 38 días con 16,000 GPUs GB200.

Aún está en post-training sin fecha de lanzamiento, pero señala que Microsoft quiere competir directamente en modelos base — atención cuando llegue a Foundry.

DigitalOcean lanza Insights: observabilidad de agentes AI en preview público

Disponible desde el 12 de octubre, Insights ofrece una vista unificada de infraestructura, apps y agentes sobre OpenTelemetry. Viene integrado con DOKS, App Platform y Managed Agents sin instrumentación adicional, y es gratuito durante el preview.

Si corres agentes en producción y necesitas trazabilidad sin montar tu propio stack de observabilidad, esto te ahorra semanas de setup.

Innovaciones técnicas con potencial práctico

🔥 Gemini 4 Argon llega a Android Studio con build loops auto-reparables

Google habilitó Gemini 4 Argon en Android Studio Canary y Antigravity CLI el 13 de octubre. El modelo detecta errores de Gradle y Kotlin, mantiene una hipótesis consistente entre ediciones, y usa análisis AST para corregir builds rotos automáticamente. Genera código Jetpack Compose con shaders GPU a 120 FPS.

Si desarrollas Android, esto cambia el flujo de trabajo diario: build errors que antes rompían tu flow ahora se resuelven solos con contexto del proyecto completo.

Android Developers • Google Blog

Gemini 4 Argon disponible en API a precio introductorio de $2/M input

El modelo está disponible para desarrolladores desde el 13 de octubre vía Gemini API y AI Studio con 1M tokens de contexto. El precio introductorio es $2/M input y $10/M output, pero se duplicará el 1 de diciembre.

Ventana de 2 meses para probar y validar si Argon funciona para tu caso de uso antes de que el precio suba — ideal para prototipar agentes de contexto largo.

🔥 Alerta de seguridad: Aoki infostealer ahora roba credenciales de AI coding tools

Symantec reportó el 15 de octubre que nuevas versiones del infostealer Aoki apuntan específicamente a archivos de configuración de Claude, Codex, Cursor, Copilot, Gemini, JetBrains AI y Kiro. Roba API keys, tokens de sesión y cookies que dan acceso a repos y pipelines CI/CD conectados.

Si usas AI coding assistants (y probablemente sí), revisa tu endpoint protection y rota tus API keys — un token robado da acceso a todo lo que tienes conectado.

🔥 Magnitude: motor de inferencia auto-optimizable 2x más rápido que llama.cpp

Magnitude es un motor de inferencia para agentes AI que se auto-optimiza según el hardware disponible, logrando hasta 2x mejor rendimiento que llama.cpp en benchmarks. Lanzado en Product Hunt la semana del 13 de octubre, apunta a equipos que necesitan inferencia local rápida sin tunear configuraciones manualmente.

Para founders que quieren correr modelos localmente en su infra sin pagar cloud, esto reduce la barrera técnica de servir modelos en producción.

Claude y ecosistema Anthropic

🔥 Claude Haiku 5.5: 90% más barato con 1M de contexto y computer use

Anthropic lanzó Claude Haiku 5.5 el 7 de octubre con pricing de $0.10/M input y $0.50/M output para prompts bajo 100K tokens — una reducción del ~90% vs Haiku 4.5. Incluye ventana de 1M tokens, effort controls, y soporte beta de computer use y browser use en los SDKs de Python y TypeScript.

A este precio, Haiku 5.5 se vuelve viable para clasificación masiva, routing de queries, y tareas de alto volumen donde antes el costo era prohibitivo.
