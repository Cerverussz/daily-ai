🔥 Microsoft Ignite 2026: Copilot Workspaces, Autopilot y Agent 365 GA

Microsoft presentó Copilot como el “sistema operativo del trabajo”. Copilot Workspaces es un espacio compartido donde empleados y agentes AI colaboran en proyectos. Autopilot maneja tareas recurrentes sin instrucciones paso a paso. Agent 365 llega a GA con gobernanza, identidad (Entra Agent Identity) y controles de costos para agentes enterprise.

Si construyes productos B2B o marketplaces, el patrón de “agente con identidad y permisos propios” ya es infraestructura estándar de Microsoft — tu arquitectura de agentes debería contemplar lo mismo.

🔥 LangSmith Tool Gateway en beta pública: control centralizado para herramientas de agentes

LangChain lanzó Tool Gateway el 19 de noviembre, una capa managed que se interpone entre tus agentes y los servidores MCP que consumen. Centraliza credenciales, identidad del caller, políticas de acceso, flujos de aprobación y trazas de auditoría. Compatible con LangChain, Claude Code, Cursor y Deep Agents.

Si ya tienes agentes en producción llamando tools via MCP, esto resuelve el problema de gobernar quién llama qué con qué credenciales, sin construirlo tú mismo.

LangChain Blog • Unite.AI

🔥 Cloudflare AI Search: haz tu sitio buscable por agentes AI con un toggle

Cloudflare agregó una opción en su dashboard que automáticamente crea una instancia de AI Search, rastrea e indexa tu sitio, y expone una API de búsqueda + endpoint MCP bajo tu dominio. Los agentes AI pueden descubrir y consultar tu contenido directamente.

Si tienes un marketplace o plataforma con contenido público, activar esto es la diferencia entre que los agentes AI de tus usuarios encuentren tu inventario o no.

🔥 Microsoft Foundry Local llega a Android: inferencia AI on-device sin cloud

Azure AI Foundry Local permite ejecutar modelos de lenguaje directamente en dispositivos Android sin roundtrips al cloud. PhonePe ya lo usa en producción en su app. No requiere GPUs dedicadas — funciona en el hardware estándar del dispositivo.

Una alternativa real a Gemini Nano para on-device AI en Android, con la ventaja de usar modelos que ya conoces del ecosistema Azure.

Microsoft Tech Community

Azure Catalyst unifica agent tooling de Azure y GitHub en un solo lugar

Anunciado en Ignite 2026, Azure Catalyst es un nuevo hub para descubrir, planificar y modernizar agentes AI. Integra las herramientas de agentes de Azure y GitHub en un solo entorno conectado, con Cobalt 200 VMs que prometen hasta 50% más rendimiento.

Si tu stack de agentes vive entre Azure y GitHub, dejas de saltar entre portales para gestionar deployments y recursos.

GitHub Copilot: el code review se cobrará a la organización desde el 30 de diciembre

A partir del 30 de diciembre de 2026, el uso de Copilot Code Review se cargará a la organización si no ha configurado una preferencia de billing. Todos los planes ya operan con AI Credits basados en consumo por modelo y tokens desde junio.

Si lideras un equipo, revisa tu config de billing de Copilot antes de fin de año para evitar cargos inesperados en la org.

🔥 Character.AI en bancarrota: 21M de cuentas y sus chats en limbo legal

Character.AI (Chapter 11 desde octubre) espera cerrar su venta supervisada por el tribunal a finales de noviembre. Disney ofertó $20M por IP y tecnología, pero excluyó los datos de chat. Lección directa para founders: tu política de datos de usuario no es solo compliance, es riesgo existencial — define desde día uno qué pasa con los datos si tu empresa cierra.

Vercel Workflow SDK 5: ejecución durable lista para producción

Vercel consolidó Workflow SDK 5 como su solución de ejecución durable. Inputs, outputs y payloads se cifran con AES-256-GCM con clave única por ejecución. Ahora disponible en todas las regiones de Vercel Functions, no solo iad1.

Si necesitas orquestar flujos multi-paso con agentes AI en tu producto (ej. procesamiento de órdenes, onboarding), esto te da durabilidad sin montar tu propia infra de colas.

Claude Sonnet 4.5 se retira de la API el 30 de noviembre

Anthropic confirma que Claude Sonnet 4.5 deja de estar disponible en la API el 30 de noviembre de 2026. Opus 4.5 se retira el 22 de enero de 2027. Los modelos actuales son Fable 5.2, Opus 5.5, Sonnet 5.5 y Haiku 5.5.

Anthropic prueba un checkpoint más potente bajo Opus 5.5

Usuarios reportan que requests a Opus 5.5 producen resultados notablemente superiores al nivel habitual, sugiriendo que Anthropic está ruteando tráfico a un checkpoint más nuevo (posiblemente Opus 5.6 o Fable 5.5). Anthropic no ha confirmado nada oficialmente.

Si usas Opus 5.5 en producción y notas mejoras inconsistentes, es probable un A/B test — no cambies tu eval pipeline aún.
