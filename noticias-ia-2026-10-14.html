🔥 Gemini 4 Argon llega a disponibilidad general para desarrolladores y empresas

Google lanzó Gemini 4 Argon en GA el 13-14 de octubre, su modelo flagship de razonamiento con ventana de contexto de 1M tokens y output largo de hasta 1M tokens. Disponible vía Gemini API, AI Studio y Google Cloud con precio introductorio de $2/M input y $10/M output hasta el 30 de noviembre.

Si construyes agentes de larga duración o pipelines de migración de código, Argon compite directamente con Opus 5.5 a precio agresivo — evalúa antes de que termine el período introductorio.

OpenAI anuncia retiro de GPT-4o y GPT-4.1 de la API para enero 2027

OpenAI notificó el 14 de octubre que los modelos GPT-4o (snapshots 2024-08-06 y 2024-11-20) y GPT-4.1 serán retirados de la API el 14 de enero de 2027. GPT-6 Luna ($0.10/M input) es el reemplazo recomendado.

Si tu producto depende de GPT-4o en backend, tienes 3 meses para migrar a Luna o evaluar alternativas — planifica tu sprint de migración ahora.

🔥 JetBrains lanza Mellum 2.1: modelo open-source de 12B para coding agents

JetBrains liberó Mellum 2.1, un modelo MoE de 12B parámetros (2.5B activos) bajo licencia Apache 2.0, entrenado con RL en sandboxes reales para explorar código, editar archivos y auto-verificar cambios. Reporta 47% en SWE-bench Verified y es compatible con vLLM, SGLang y Ollama.

Un modelo de coding auto-hosteable con licencia permisiva y benchmark competitivo — ideal si quieres un coding agent privado sin depender de APIs cloud.

NVIDIA anunció la variante de 64GB del DGX Spark con Grace Blackwell, capaz de ejecutar modelos de hasta 100B parámetros localmente. Incluye DGX OS con Ollama, vLLM y NVIDIA Agent Toolkit, soporta clustering de dos unidades, y estará disponible desde el 23 de octubre.

Por primera vez tienes un desktop sub-$5K que corre agentes AI locales con modelos serios — perfecto para prototipar sin enviar datos a la nube.

🔥 Claude Haiku 5.5: reducción de 90% en precios de API

Anthropic lanzó Claude Haiku 5.5 el 7 de octubre a $0.10/M input y $0.50/M output (hasta 100K tokens), una reducción del 90% vs Haiku 4.5. Incluye ventana de 1M tokens, thinking adaptativo con esfuerzo ajustable, y 128K de output máximo.

A una décima del precio anterior, Haiku 5.5 hace viable usar Claude para clasificación, resúmenes y sub-agentes de alto volumen sin destruir tu presupuesto de API.

OpenTelemetry llega a Claude Platform en public beta

Anthropic habilitó el 14 de octubre la exportación de trazas OpenTelemetry para la API de Messages y sesiones de Managed Agents, con SDKs en Python, TypeScript, Go, Java, C#, PHP y Ruby. La configuración se hace desde la Claude Console añadiendo un destino OTEL.

Si corres Claude en producción, ahora puedes trazar requests en tu stack de observabilidad existente (Datadog, Grafana) sin instrumentación custom.

CryptoBriefing • Claude Platform Docs

Dynamic Workflows en Managed Agents: hasta 1,000 agentes por ejecución

Anthropic lanzó Dynamic Workflows el 9 de octubre, permitiendo que un agente escriba y ejecute workflows que orquestan hasta 1,000 sub-agentes (64 concurrentes) en fases. En pruebas internas, un workflow encontró 66 de 70 bugs plantados vs 14-27 de un agente individual.

Para tareas complejas como auditorías de código o análisis masivo de datos, esto escala sin que tengas que construir tu propio orquestador.
