🔥 GitSpawn: vulnerabilidad en .git/config afecta 7 coding agents incluyendo Claude Code, Codex y Cursor

Manifold Security reveló que un atacante puede inyectar código malicioso via core.fsmonitor en .git/config, que se ejecuta cuando el agente hace git status — fuera del sandbox, sin prompt de aprobación. Afecta a Claude Code, OpenAI Codex, Cursor, Goose, Hermes Agent, Qwen Code y Grok Build. Cuatro de los siete seguían sin parche al 1 de septiembre.

Si usas coding agents en repos que no controlas (open source, PRs externos), actualiza ya: Claude Code 2.1.196+, Codex CLI 0.131.0+, Cursor 3.0.0+.

🔥 DeepSeek V4.1 Flash: supera a V4 Pro con solo 8B parámetros activos a $0.30/M tokens

DeepSeek lanzó V4.1 Flash, un modelo MoE de 552B parámetros con 8B activos en input y 16B en output. Múltiples evaluadores independientes confirman que supera a V4-Pro en rendimiento, costo y latencia. Desde el 14 de septiembre, requests a V4-Pro via API serán servidos por V4.1-Flash automáticamente.

A $0.30 input / $1.20 output por millón de tokens, es el modelo más eficiente para pipelines de alto volumen en tu backend — ideal para RAG, clasificación y agentes.

Devin Voice: coding por voz full-duplex con el nuevo modelo SWE-2

Cognition lanzó Devin Voice, un modo de voz full-duplex donde puedes hablar con Devin mientras él escucha, responde, levanta entornos, modifica código y corre tests en paralelo. Usa GPT-Live para la voz y su nuevo modelo SWE-2 de 2.8T parámetros entrenado con RL.

La interfaz de voz para coding agents cambia el flujo de trabajo: puedes discutir arquitectura con Devin mientras él ejecuta, sin tocar el teclado.
