Aplicaciones profesionales de IA

🔥 WebMCP en Chrome 149: nuevo estándar abierto para que webs expongan herramientas a agentes AI

Google lanzó WebMCP como origin trial en Chrome 149, un estándar web abierto que permite a sitios web exponer funciones estructuradas (JavaScript o anotaciones HTML) directamente a agentes AI en el navegador, sin necesidad de un servidor MCP backend. Booking.com, Shopify, Instacart, Expedia y Redfin ya están experimentando con la integración.

Si tienes un marketplace o SaaS web, implementar WebMCP es lo que hará que tu plataforma sea consumible por agentes AI — el nuevo canal de adquisición.

Chrome Developers • ScriptWalker

🔥 Android Studio Migration Assistant: convierte apps React Native, iOS o web a Kotlin nativo con AI

Google presentó en I/O 2026 un agente de migración integrado en Android Studio que analiza código de React Native, frameworks web o iOS y genera una app nativa en Kotlin con Jetpack Compose, convirtiendo storyboards, SVGs y assets automáticamente. Migraciones que tomaban semanas ahora se completan en horas.

Si mantienes un proyecto cross-platform y estás considerando ir nativo en Android, esta herramienta elimina la mayor barrera de entrada.

Innovaciones técnicas con potencial práctico

🔥 Google Antigravity 2.0: plataforma agent-first con CLI, SDK y subagentes dinámicos

Google relanzó su herramienta de coding como Antigravity 2.0: una app desktop rediseñada, un CLI que reemplaza a Gemini CLI (deprecado el 18 de junio), un SDK público, subagentes dinámicos, tareas en background programadas, y Gemini 3.5 Flash como modelo por defecto. Comparte el mismo harness entre desktop y terminal.

Es el competidor directo de Claude Code desde Google — si usas Gemini CLI, tienes hasta el 18 de junio para migrar a Antigravity CLI.

TechCrunch • Google Developers

🔥 Koog 1.0 de JetBrains: framework estable de agentes AI para Kotlin y Java en producción

JetBrains lanzó Koog 1.0, su framework open-source de agentes AI para JVM con garantía de estabilidad de API de 1 año. Incluye DSL idiomático en Kotlin, API fluida para Java, soporte de OpenTelemetry multiplataforma, transporte HTTP desacoplado, y prompt caching nativo para Anthropic.

Si tu backend es Kotlin/Java y querías integrar agentes AI sin migrar a Python, Koog 1.0 es la primera opción production-ready del ecosistema JVM.

JetBrains Blog • GitHub

GitHub Copilot migra a AI Credits el 1 de junio: nuevo modelo de pricing basado en uso

GitHub Copilot abandona su modelo de suscripción fija y pasa a AI Credits el 1 de junio de 2026, un sistema de créditos basado en consumo real. Copilot ahora soporta modelos de OpenAI, Anthropic (Claude Haiku/Sonnet/Opus), Google (Gemini 3), y xAI Grok Code, permitiendo elegir modelo por tarea.

Revisa tu consumo actual — según tu volumen, el cambio a créditos puede abaratarte o encarecerte significativamente.

Creación de negocios y productos con IA

🔥 Google AI Studio genera apps Android nativas desde un prompt de texto

Google AI Studio ahora permite describir una app en lenguaje natural y genera una aplicación Android nativa funcional con Kotlin, Jetpack Compose y patrones recomendados de la plataforma. El código generado es production-quality y sigue las mejores prácticas del ecosistema Android.

Para validar una idea de app Android rápidamente, esto reduce el tiempo de prototipo funcional de días a minutos — ideal para MVPs antes de invertir en arquitectura.

Google Blog • Technobezz

🔥 SuperDesign: primer agente open-source de diseño UI que vive dentro del IDE

SuperDesign es un agente de diseño AI open-source que se integra en VS Code, Cursor, Windsurf y Claude Code, generando mockups, wireframes y componentes UI desde prompts en lenguaje natural. Elimina el cambio entre herramientas de diseño y código, acelerando la fase de prototipado visual.

Si eres founder técnico sin diseñador, esto te da UI profesional sin salir del editor — y al ser open-source, lo adaptas a tu design system.

Claude y ecosistema Anthropic

Claude Code v2.1.152: claude agents, /usage desglosado y diffs navegables con teclado

La última versión de Claude Code (26 de mayo) introduce claude agents, una pantalla unificada para ver todas tus sesiones activas, bloqueadas o completadas. Además, /usage ahora muestra desglose por categoría (skills, subagentes, plugins, costo por servidor MCP), y la vista de diffs es navegable por teclado.

Si manejas múltiples sesiones de Claude Code en paralelo, claude agents te da visibilidad real sobre qué está pasando sin cambiar de terminal.

GitHub Releases • Releasebot

Anthropic lanza MCP Tunnels y Sandboxes self-hosted para Managed Agents

MCP Tunnels permite que Managed Agents se conecten a servidores MCP privados sin exponer puertos al internet, usando una conexión saliente cifrada. Los Sandboxes self-hosted (beta pública) permiten ejecutar herramientas de agentes en infraestructura propia o de providers como Cloudflare, Daytona, Modal y Vercel.

Esto desbloquea Managed Agents para empresas que no podían enviar datos a Anthropic — ahora la ejecución queda en tu perímetro.
