Aplicaciones profesionales de IA

🔥 WebMCP: Google propone estándar web abierto para que agentes AI interactúen con cualquier sitio

Anunciado en Google I/O, WebMCP permite a developers exponer funciones JavaScript y formularios HTML como herramientas estructuradas para agentes AI en el browser, eliminando el scraping visual. Shopify, Booking.com, Instacart, Intuit y Expedia ya experimentan con el estándar, que se incuba en el W3C junto con Microsoft.

Si tienes un marketplace o SaaS, exponer tus acciones via WebMCP hará que agentes AI puedan operar tu plataforma como first-class citizens — origin trial ya disponible en Chrome 149.

Chrome Dev Blog • PYMNTS • The New Stack

🔥 Android CLI 1.0 + Android Skills open-source: Google abre Android Studio a agentes AI

Google lanzó Android CLI 1.0 estable, que permite a agentes AI usar Android Studio directamente: descargar SDKs, compilar y ejecutar apps en dispositivos. Además, open-sourceó “Android Skills”, un conjunto de instrucciones para que LLMs ejecuten migraciones complejas como pasar a Jetpack Compose o Navigation 3.

Esto convierte a tu agente de coding favorito (Claude Code, Cursor) en un Android developer asistido que puede compilar y testear directamente en tu pipeline.

The Next Web • Google Dev Blog

🔥 Android Studio Migration Agent: migra apps React Native, iOS o web a Kotlin nativo con AI

Google previewó un agente de migración en Android Studio que analiza código de React Native, frameworks web o iOS y lo convierte a apps Kotlin nativas. Migraciones que tomaban semanas ahora se reducen a horas según Google.

Si tienes un producto cross-platform y quieres ir nativo en Android para rendimiento o acceso a APIs del sistema, la barrera de entrada acaba de bajar drásticamente.

AndroidGuys • Android Developers Blog

Innovaciones técnicas con potencial práctico

🔥 Gemini 3.5 Flash: supera a 3.1 Pro en coding y agentes a $1.50/M tokens de input

Google lanzó Gemini 3.5 Flash en I/O 2026, un modelo que supera a Gemini 3.1 Pro en benchmarks de coding, agentes y multimodal, siendo 4x más rápido en output tokens/segundo. Cuesta $1.50/M input y $9/M output (~40% más barato que 3.1 Pro) y es gratis en la app Gemini y en AI Mode de Search.

Relación calidad-precio agresiva para pipelines de agentes en backend — y gratis para prototipado rápido en AI Studio.

CNBC • FelloAI

🔥 Antigravity 2.0: la plataforma agent-first de Google con subagentes y sandboxing nativo

Google actualizó Antigravity a 2.0 con un nuevo CLI que permite crear subagentes especializados para workflows complejos, con sandboxing cross-platform integrado, credential masking y políticas de Git reforzadas. Es la respuesta directa de Google a Claude Code para desarrollo agéntico.

Si ya usas Claude Code o Cursor, Antigravity 2.0 compite directamente en el espacio de agentes de coding con la ventaja de integración nativa con el ecosistema Android y GCP.

PPC Land • Android Headlines

Gemini Spark: agente personal 24/7 que trabaja en background con Google Workspace

Google presentó Gemini Spark, un agente personal que no espera prompts — gestiona tareas autónomamente en Gmail, Docs y Slides 24/7. Powered by Gemini 3.5, está en beta para trusted testers y suscriptores de Google AI Ultra.

Es el primer intento serio de Google de un agente autónomo tipo “background worker” integrado en las herramientas que ya usas a diario.

Creación de negocios y productos con IA

🔥 Google AI Studio ahora genera apps Android nativas desde texto y las despliega con un click

Google AI Studio incorpora soporte nativo de Kotlin para generar apps Android completas desde un prompt de texto, con previsualización en vivo, integración con Google Workspace, y deploy con un click a Cloud Run + Firebase. Además, Managed Agents en la Gemini API elimina la fricción de infraestructura: una sola llamada API te da un agente con sandbox Linux aislado.

El tiempo de “idea a app Android funcional desplegada” se reduce a minutos — ideal para validar MVPs o prototipos rápidos antes de invertir en desarrollo completo.

Developer Tech • Android Headlines

🔥 Information Agents en Google Search: agentes que monitorean marketplaces y webs 24/7 por ti

Google introdujo “Information Agents” en Search: agentes personalizados que trabajan en background rastreando sitios web, redes sociales y marketplaces online, y te notifican cuando encuentran lo que necesitas. AI Mode de Search ya supera los mil millones de usuarios mensuales.

Si operas un marketplace, tus usuarios podrán crear agentes que monitoreen tu inventario automáticamente — tu plataforma necesita ser agent-friendly (y WebMCP es el camino).

Google Blog • Technology.org

Claude y ecosistema Anthropic

Anthropic lanza MCP Tunnels y Self-Hosted Sandboxes para Claude Managed Agents

Anunciado en Code with Claude London el 19 de mayo, MCP Tunnels permite a agentes acceder a servidores MCP dentro de tu red privada sin exponer endpoints públicos (research preview). Self-Hosted Sandboxes (public beta) mueve la ejecución de herramientas a tu propia infra o providers como Cloudflare, Daytona, Modal y Vercel, mientras la orquestación queda en Anthropic.

Si necesitas agentes AI que accedan a tus APIs internas o bases de datos sin exponer nada a internet, esto resuelve el problema de seguridad que frenaba adopción enterprise.

The Decoder • InfoQ • The New Stack

🔥 Google Health reemplaza Fitbit hoy: coach AI con Gemini a $9.99/mes

A partir del 19 de mayo, la app Fitbit se convierte en Google Health con un rediseño completo. El nuevo Google Health Coach, powered by Gemini, actúa como entrenador fitness, experto en sueño y asesor de bienestar 24/7. Integra datos de Health Connect, Apple Health y registros médicos. Cuesta $9.99/mes o $99/año con Google Health Premium.

Google acaba de poner un coach AI personalizado en el bolsillo de millones de usuarios Fitbit — el estándar que cualquier app de wellness o sports tech necesita igualar.
