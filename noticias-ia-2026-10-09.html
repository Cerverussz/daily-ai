Aplicaciones profesionales de IA

🔥 Harness adquiere assets de Augment Code: nace Cosmos, el agente autónomo de desarrollo

Harness anunció la adquisición de Cosmos, Auggie CLI y el Code Context Engine de Augment Code. Cosmos se convierte en el “Software Factory Agent” de Harness: planifica cambios, escribe código y tests en VMs aisladas, y abre PRs listas para revisión humana, integrándose con los agentes de delivery, seguridad y costos de Harness.

Si ya usas CI/CD de Harness, ahora tienes un agente de coding integrado en tu pipeline — el ciclo completo de “código a producción” se reduce a revisar PRs.

Atlassian + OpenAI: GPT-6 llega a Rovo con agentes para gestión de proyectos

Atlassian y OpenAI expandieron su alianza para integrar modelos GPT-6 en Rovo y los agentes de Atlassian. Rovo combina estos modelos con el Teamwork Graph (personas, proyectos, docs, decisiones) para generar evaluaciones de launch-readiness cruzando tickets de Jira, páginas de Confluence y discusiones.

Para equipos que ya viven en Jira/Confluence, esto convierte contexto de proyecto disperso en insights accionables sin salir de la plataforma.

OpenAI • Channel Insider

🔥 OpenAI Decisions API en beta pública: clasificación a $0.10/M tokens

La Decisions API (/v1/decisions) salió de preview limitado a beta pública. En vez de generar texto, responde preguntas definidas por el developer sobre inputs de texto o imagen, retornando predicados, opciones y scores. Corre sobre GPT-6 Luna, es hasta 10x más rápida que la Responses API y no cobra output tokens.

A $0.10/M tokens sin cargo de output, es ideal para clasificación, moderación y routing en marketplaces con alto volumen de contenido.

Innovaciones técnicas con potencial práctico

🔥 EmbeddingGemma 2: embeddings multimodales on-device en 567 MB de RAM

Google lanzó EmbeddingGemma 2, modelo open-source (Apache 2.0) de 740M parámetros que mapea texto, código, imágenes, video y audio a un espacio de 768 dimensiones compartido. Corre en un Pixel 11 Pro con ~567 MB de RAM (191 MB solo texto) y soporta contexto de 8K tokens — 4x más que su predecesor.

Un modelo de embeddings multimodal que corre on-device abre la puerta a búsqueda semántica offline en apps Android sin depender de APIs cloud.

Mistral lanza Le Chonk (Large 4): 1T parámetros open-weight con visión y razonamiento

Mistral presentó su modelo más grande: una arquitectura MoE de 1 billón de parámetros (~49B activos) con encoder de visión de 1.6B params y ventana de contexto de 1M tokens. Está en developer preview con disponibilidad completa prometida para finales de octubre.

Otro contendiente open-weight serio para self-hosting: si tu caso de uso necesita multimodalidad sin vendor lock-in, ahora hay más opciones competitivas.

OpenAI Intelligent UI: ChatGPT pasa de chatbot a interfaz visual interactiva

OpenAI lanzó Intelligent UI con GPT-6, permitiendo que las respuestas de ChatGPT incluyan botones interactivos, calculadoras, gráficos editables, diagramas y mapas en vez de solo texto. Los usuarios pueden reducir los elementos visuales si prefieren respuestas tradicionales.

Creación de negocios y productos con IA

🔥 Personal Agent Protocol: Sierra y Meta publican estándar abierto para agentes personales

Sierra y Meta anunciaron el Personal Agent Protocol (PAP), un estándar abierto para que agentes AI personales interactúen con negocios de forma segura. Usa OAuth para sesión, los consumidores controlan qué acceso da su agente, y los negocios definen límites. Shopify, Stripe, Walmart y Genesys ya son partners; spec v0.1 sale a finales de octubre.

Si tienes un marketplace o plataforma de servicios, este protocolo definirá cómo los agentes AI de tus usuarios interactuarán con tu negocio — vale la pena seguirlo de cerca.

Google lanza agente Gemini universal para Workspace: un solo agente para Gmail, Drive, Docs y Calendar

Google presentó un agente Gemini unificado que opera dentro de Gmail, Drive, Docs y Calendar, capaz de responder preguntas, escribir y ejecutar código, crear documentos y coordinar sub-agentes. Es parte de la consolidación de herramientas dev bajo la marca Antigravity.

Claude y ecosistema Anthropic

Claude Haiku 5.5: 75% más barato que Haiku 4.5, con effort controls

Anthropic lanzó Claude Haiku 5.5 a $0.10/$0.50 por millón de tokens (input/output) para prompts de hasta 100K tokens — ~10x más barato que Haiku 4.5. Es el primer modelo Haiku con ajuste de esfuerzo (effort setting), permitiendo a devs intercambiar costo por rendimiento. Disponible en Claude Platform, AWS, GCP y Azure.

A ese precio, es viable usar Haiku 5.5 para sub-agentes, clasificación masiva y procesamiento de alto volumen donde antes tenías que sacrificar calidad.
