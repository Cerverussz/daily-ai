🔥 Google Android Show: Gemini Intelligence convierte Android en un sistema operativo agente

En el Android Show: I/O Edition (12 de mayo), Google presentó Gemini Intelligence: el asistente entiende el contexto de pantalla, ejecuta tareas multi-paso (armar carritos de compra, hacer reservas, rellenar formularios) y llega a Chrome con auto-browse agente. También anunció vibe-coded widgets — creas widgets con lenguaje natural — y Gemini en Android Auto con pedidos de comida vía DoorDash.

Si desarrollas apps Android, tu superficie de integración con Gemini acaba de multiplicarse: automatización de tareas, widgets generados por AI, y un browser agente son features que tus usuarios van a esperar.

🔥 AWS retira Amazon Q Developer el 15 de mayo; Kiro lo reemplaza con desarrollo basado en specs

AWS bloqueó nuevos signups de Amazon Q Developer desde el 15 de mayo, redirigiendo a Kiro como su IDE agente de cabecera. Kiro trabaja con specs estructuradas en lugar de prompts individuales: defines requisitos en lenguaje natural con criterios EARS, y el agente planifica, implementa y verifica cambios en todo el codebase. Incluye hooks automatizados, steering files y subagentes custom.

Si usabas Q Developer, la migración es ahora; y el enfoque spec-driven de Kiro es relevante para cualquier founder que quiera que su AI coding sea reproducible y auditable.

GitHub Copilot migra a créditos AI el 1 de junio — agent mode multiplica el consumo

GitHub Copilot abandona el modelo flat de suscripción por billing basado en AI Credits (1 crédito = $0.01 USD). Copilot Pro+ incluye $39/mes en créditos, Business $19/usuario. El agent mode, que ejecuta múltiples llamadas al modelo por tarea, puede consumir cientos de créditos en una sola sesión de refactoring multi-archivo.

Si dependes de Copilot agent mode para tareas pesadas, haz los números antes del 1 de junio — podrías terminar pagando significativamente más que con la tarifa plana.

GitHub Blog • JudyAI Lab

Claude Code añade Agent View y /goal: sesiones autónomas que trabajan hasta cumplir un objetivo

La última actualización de Claude Code trae Agent View (research preview), un dashboard único para ver todas las sesiones — activas, bloqueadas o completadas. El nuevo comando /goal permite definir una condición de completado y Claude sigue trabajando across turns hasta cumplirla, con overlay en vivo de tiempo, turnos y tokens consumidos.

El /goal convierte a Claude Code en un agente fire-and-forget real — defines el objetivo, lo dejas correr, y revisas cuando termina.

🔥 Claude Code Desktop rediseñado: sesiones paralelas, terminal integrado y editor en una sola ventana

Anthropic rediseñó la app de escritorio de Claude Code para trabajo paralelo real: sidebar con todas las sesiones (activas, archivadas, filtradas por proyecto), side chats con contexto heredado (⌘+;), terminal integrado para tests y builds, editor de archivos in-app, y diff viewer optimizado para changesets grandes. Anthropic lanza Dreaming y Multi-agent Orchestration para Managed Agents

Tres features nuevos para Managed Agents: Dreaming permite que los agentes revisen sus sesiones pasadas entre trabajos para extraer patrones y auto-mejorar (similar a consolidación de memoria durante el sueño). Multi-agent Orchestration deja que un agente líder delegue subtareas a especialistas que corren en paralelo con filesystem compartido. Outcomes agrega auto-evaluación con rúbricas que mejoran task completion hasta 10 puntos. Harvey reportó un salto de 6x en tasa de completado.

Si construyes agentes con la API de Claude, Dreaming y Orchestration te ahorran implementar tu propia capa de memoria persistente y coordinación multi-agente.

9to5Mac • SiliconANGLE

Claude Platform llega a AWS: API, Managed Agents y billing nativo con IAM

Anthropic lanzó Claude Platform on AWS, llevando toda la API de Claude (Messages, Files, Batches), Managed Agents, Agent Skills, code execution y tool use a infraestructura gestionada por Anthropic pero accesible con billing de AWS e IAM authentication. Es un endpoint nativo de AWS, no un wrapper.

Si tu infra ya está en AWS, puedes integrar Claude sin gestionar API keys separadas ni reconciliar facturas — todo va en tu cuenta de Amazon.
