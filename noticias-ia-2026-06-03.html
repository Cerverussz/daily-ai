Aplicaciones profesionales de IA

🔥 Microsoft lanza MAI-Code-1-Flash en GitHub Copilot: modelo propio de 5B params para coding

En Build Day 2, Microsoft presentó MAI-Code-1-Flash, un modelo de 5 mil millones de parámetros construido internamente y optimizado para el harness de GitHub Copilot y VS Code. Supera a Claude Haiku 4.5 en SWE-Bench Verified, Pro y Multilingual, con +16 puntos en SWE-Bench Pro (51.2% vs 35.2%), e incluye pensamiento adaptativo que ajusta su presupuesto de razonamiento según la complejidad de la tarea.

Microsoft ya no depende solo de OpenAI para Copilot — este modelo propio es más rápido y barato para autocompletado diario, lo que debería mejorar la experiencia sin costo extra.

Microsoft AI • GitHub Blog

🔥 GitHub Copilot migra a facturación por uso con AI Credits desde el 1 de junio

Todos los planes de Copilot pasaron a facturación basada en créditos AI, reemplazando las premium request units (PRUs). El plan Pro ($10/mes) incluye 1,000 créditos base + 500 flex; Pro+ ($39) incluye 3,900 + 3,100; y el nuevo plan Max ofrece 10,000 + 10,000 créditos mensuales.

Si usas agentes de Copilot intensivamente, ahora pagas proporcional al compute real — calcula tu consumo actual antes de que termine el periodo de gracia flex en septiembre.

GitHub Blog • FindSkill.ai

Visual Studio 2026: agentes Copilot para debugging, profiling y modernización .NET

Microsoft anunció que GitHub Copilot en Visual Studio evoluciona hacia agentes que participan activamente en el ciclo de desarrollo: debugging, profiling y testing junto al dev. También llega Copilot modernization agent para upgrades automáticos de aplicaciones al último stack .NET.

Si mantienes un backend .NET, el agente de modernización puede ahorrarte semanas de migración manual entre versiones de framework.

Innovaciones técnicas con potencial práctico

MAI-Thinking-1: Microsoft presenta su primer modelo de razonamiento, rivaliza con Opus 4.6 en coding

Anunciado en Build Day 2, MAI-Thinking-1 es un modelo de 35 mil millones de parámetros activos con 256K de contexto, diseñado para razonamiento multi-paso complejo y generación de código. En tests ciegos, evaluadores independientes lo prefieren a Sonnet 4.6, y empata con Opus 4.6 en SWE-Bench Pro.

Un modelo de razonamiento competitivo a bajo costo de tokens amplía tus opciones para pipelines que requieren planificación compleja sin pagar precios de modelo frontier.

Microsoft Build Live • GizBot

Claude Opus 4.8 + Dynamic Workflows: orquesta cientos de subagentes en paralelo desde Claude Code

Anthropic lanzó Opus 4.8 el 28 de mayo (41 días después de Opus 4.7), con 88.6% en SWE-Bench Verified y un nuevo research preview de Dynamic Workflows que permite a Claude Code dividir tareas grandes en cientos de subagentes paralelos en una sola sesión. Ya puede ejecutar migraciones a escala de codebase completo, usando la test suite existente como barra de calidad.

Si estás haciendo refactors o migraciones grandes, Dynamic Workflows convierte lo que antes era un proyecto de semanas en algo que corre en una sesión de Claude Code.

Anthropic • TechCrunch

Cursor Composer 2.5: modelo propio que iguala Opus 4.7 a $0.50/M tokens de input

Cursor lanzó Composer 2.5, un modelo in-house de horizonte largo que empata con Opus 4.7 y GPT-5.5 en benchmarks, a $0.50/M input y $2.50/M output. Incluye Build in Parallel para ejecutar múltiples tareas simultáneamente y review de PRs integrado.

Para edición diaria de código, Composer 2.5 ofrece calidad frontier a una fracción del precio — el combo Cursor + Claude Code terminal se consolida como el stack dominante.

NxCode • The New Stack

🔥 MiniMax M3: modelo open-weight que supera a GPT-5.5 al 5-10% del costo

El laboratorio chino MiniMax lanzó M3 el 1 de junio, un modelo open-weight con 1M tokens de contexto, visión nativa de imagen/video y coding agente. Usa la arquitectura MSA (MiniMax Sparse Attention) que reduce el compute por token a 1/20 del estándar. Resultados: 59.0% en SWE-Bench Pro (superando a GPT-5.5 y Gemini 3.1 Pro) y 83.5 en BrowseComp (vs 79.3 de Opus 4.7).

Un modelo open-weight con rendimiento frontier a 5-10% del costo cambia fundamentalmente la economía de correr features AI-heavy en producción si eres founder bootstrapped.

VentureBeat • MiniMax Blog

🔥 KPMG despliega Claude a 276,000 empleados integrado en Digital Gateway con Managed Agents

KPMG y Anthropic firmaron alianza global: Claude queda embebido en Digital Gateway (la plataforma de trabajo real de KPMG), no como chatbot aparte. Usan Claude Cowork para asistencia colaborativa y Managed Agents API para ejecución autónoma multi-paso, empezando por herramientas para clientes de tax y legal.

Este es el template para vender AI a enterprise: no un chat genérico sino agentes integrados en el workflow existente del cliente — patrón replicable si construyes SaaS B2B.

🔥 Google reimagina Search con ads conversacionales: Bloomberg reporta alarma entre anunciantes

Google anunció el cambio más grande en Search en 25 años: el buscador será "completamente reimaginado" con IA, incluyendo "conversational discovery ads" dentro de las respuestas de Gemini donde un agente chat puede cerrar la venta sin que el usuario visite la web del anunciante.
