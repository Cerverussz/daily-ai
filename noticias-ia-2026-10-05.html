🔥 Reflection AI lanza Beam: modelo open-weight de 501B parámetros para coding y agentes

Reflection AI, startup respaldada por Nvidia y fundada por ex-investigadores de Google DeepMind, lanzó Beam: un modelo Mixture-of-Experts de 501B parámetros totales (23B activos) entrenado en 23.8 trillones de tokens con RL en 10,500 GPUs GB300. Compite con GLM-5.2 usando 3-4x menos compute en inferencia, con foco específico en coding y tareas agénticas.

Un modelo open-weight competitivo en coding con solo 23B params activos significa que puedes correrlo en tu propia infra a una fracción del costo de modelos cerrados equivalentes.

AWS refuerza infraestructura para AI agéntica: deployment cuantizado con Unsloth y capa semántica Stardog

Innovaciones técnicas con potencial práctico

🔥 Strata: motor open-source corre modelos de 125B parámetros en GPU gamer de 12GB

Strata es un motor de inferencia MIT-licensed que ejecuta Qwen3.8-Flash-Next (125B params) en una sola GPU de consumo con 12GB de VRAM y 32GB de RAM. Distribuye trabajo entre GPU, RAM, CPU y SSD, logrando 53-94 tokens/segundo en una RTX 5070 con instalación de un solo script y APIs compatibles con OpenAI y Anthropic.

Si los benchmarks se reproducen externamente, correr un modelo de 125B en hardware de menos de $1,000 cambia el cálculo local-vs-API para cualquier equipo con datos sensibles.

🔥 Google LiteRT-LM: Gemma 4 corre on-device en Android, iOS y web con 2.2x de speedup

LiteRT-LM es el runtime optimizado de Google para ejecutar Gemma 4 directamente en dispositivos móviles. Soporta Multi-Token Prediction (2.2x más rápido), Thinking Mode y Constrained Decoding, con variantes de 2B (607MB en iOS) y 4B parámetros. Incluye nuevas APIs nativas en Swift y WebGPU para browsers.

Gemma 4 E2B corriendo en 607MB de RAM significa que puedes agregar AI on-device a tu app Android sin excluir dispositivos de gama media.

Claude y ecosistema Anthropic

🔥 Claude Code Mods: plugins TypeScript que convierten al agente en plataforma extensible

Anthropic lanzó “Mods” para Claude Code: funciones TypeScript que se enganchan al pipeline de ejecución del agente y pueden reescribir prompts, interceptar tool calls, aprobar/denegar permisos, redactar secretos, y reemplazar componentes de UI. Anthropic ya convirtió 3 features internos (diff pane, agents.md loader, telemetría) en mods, señalando que el sistema es load-bearing.

Esto convierte a Claude Code de herramienta a plataforma — si tienes un workflow específico para tu proyecto, ahora puedes codificarlo como un mod reutilizable.

Claude Sonnet 5.5 GA: nuevo modelo frontier disponible en todas las plataformas

Claude Sonnet 5.5 está disponible en la API de Claude, Amazon Bedrock, Google Cloud y Microsoft Foundry. Sonnet 4.5 fue deprecado el 30 de septiembre con retiro programado para noviembre 30. Adicionalmente, la API de Models ahora incluye un campo “line” para agrupar modelos sin parsear IDs.

Si aún usas Sonnet 4.5 en producción, tienes hasta noviembre para migrar — el campo “line” facilita manejar modelos programáticamente.
