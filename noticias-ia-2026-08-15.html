Innovaciones técnicas con potencial práctico

🔥 Qwen 3.8 27B: el modelo open-source denso más capaz para agentes on-device

Alibaba lanzó Qwen3.8-27B el 14 de agosto bajo Apache 2.0: un modelo visión-lenguaje de 27B parámetros con 262K tokens de contexto, encoder de visión integrado, y capacidades de computer-use y browser-use. Salta de 13.3 a 42.2 en DeepSWE y de 63.9 a 84.3 en OSWorld-Verified vs su predecesor.

Un modelo denso de 27B con visión y tool-use bajo Apache 2.0 es exactamente lo que necesitas para agentes on-device en Android o pipelines de procesamiento visual sin depender de APIs cloud.

Medium • Lovable Blog

OpenAI Ultrafast: GPT-5.6 Sol a 750 tokens/segundo con Cerebras

OpenAI y Cerebras presentaron Ultrafast, un tier de API que ejecuta GPT-5.6 Sol hasta 14x más rápido que el tier estándar, alcanzando 750 tokens de salida por segundo. Está en preview limitado sin precio publicado aún.

Para agentes en el critical path de tu producto donde cada segundo cuenta, esto cambia la ecuación — pero sin precio confirmado, es un watch-and-wait por ahora.

TechTimes • Cerebras Blog

🔥 Meta Muse Glimmer: 30B param, agentes locales, Apache 2.0, corre en una sola GPU

Meta liberó Muse Glimmer, un modelo de 30B parámetros destilado de Muse, optimizado para workflows agénticos locales. Con cuantización a 4-bit cabe en 20GB de VRAM e incluye visión, coding, tool-calling y recuperación autónoma de fallos. Logra 75.5 en MCP Atlas y 51.2 en SWE-Bench Pro.

Un modelo agéntico que corre en hardware consumer con Apache 2.0 es ideal para prototipar agentes locales en tu producto sin costos de inference cloud.

VentureBeat • Hugging Face

Gemini 3.7 Flash: el workhorse de coding de Google a mitad de precio

Google lanzó Gemini 3.7 Flash el 13 de agosto, solo 3 semanas después de 3.6 Flash. Sube de 49% a 65.3% en DeepSWE y mejora generación de apps web funcionales. Precio introductorio: $0.75/M input, $3.75/M output — la mitad del modelo anterior.

A ese precio y con las mejoras en coding, es una opción seria para tareas de generación de código de alto volumen en tu pipeline de desarrollo.

Aplicaciones profesionales de IA

🔥 MAI-Code-1.1-Flash: Microsoft mete visión en su modelo de coding para Copilot, 73% más barato

Microsoft lanzó MAI-Code-1.1-Flash el 11 de agosto en GitHub Copilot, añadiendo soporte nativo de visión para entender imágenes junto con mejoras en calidad de código, instrucción following y tool-use. Cuesta 73% menos que MAI-Code-1-Flash.

Un modelo de coding con visión integrada a precio de Flash significa que Copilot ahora puede entender screenshots de bugs, mockups de UI y diagramas directamente — game changer para workflows de desarrollo.

NamoWork: plataforma con 500+ agentes AI especializados para equipos pequeños

Si estás construyendo como founder solo o equipo pequeño, esto reduce el plumbing de orquestar múltiples agentes — te enfocas en tu lógica de negocio.

Claude Code: subagent forking, cross-session mentions y soporte GitLab MR

Las últimas actualizaciones de Claude Code incluyen forking de subagentes que hereda contexto y prompt cache, menciones cross-session con SendMessage, soporte para merge requests de GitLab, y mejoras en self-hosted runners para planes Team y Enterprise.

El subagent forking con herencia de cache significa workflows de coding más complejos sin perder contexto — ideal para refactors grandes o auditorías de código.

MCP supera 950 servidores con nueva spec 2026-07-28: stateless core y OAuth enterprise

El directorio de conectores MCP de Claude lista más de 950 servidores. La nueva spec MCP 2026-07-28 trae un core stateless, autorización OAuth/OIDC reforzada, extensiones versionadas para Apps y Tasks, y soporte para UI embebida y túneles de red privada.

Si expones una API o servicio, implementar un MCP server ya no es opcional — es cómo tus usuarios interactuarán contigo vía agentes AI.

🔥 Technogym BioStrength: línea de fuerza con AI que ajusta carga, tempo y rango automáticamente
