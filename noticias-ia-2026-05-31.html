Innovaciones técnicas con potencial práctico

🔥 GitHub Copilot cambia a billing por uso desde el 1 de junio: completions ilimitados, agentes con créditos

A partir de mañana todos los planes de GitHub Copilot migran a AI Credits (1 crédito = $0.01 USD) basados en consumo de tokens por modelo. Los precios base no cambian ($10-$39/mes), code completions y next edit suggestions siguen siendo ilimitados, pero las funciones agente y modelos premium consumen créditos.

Si tu equipo usa Copilot intensivamente con agentes o modelos premium, revisa el preview de billing antes de que te sorprenda la factura de junio.

GitHub Blog • GitHub Docs

🔥 Android Studio I/O Edition: Agent Mode que arquitecta, testea y debuguea apps completas

La nueva edición de Android Studio incluye un agente que va más allá de sugerir código: planifica arquitectura, escribe tests y corrige bugs autónomamente. Además, el migration agent convierte apps de React Native, web o iOS a Kotlin nativo en horas en vez de semanas, y el Android CLI permite que agentes AI externos usen el poder de Android Studio.

Para devs Android, esto cambia el flujo diario: el agente maneja el boilerplate y las migraciones, tú te enfocas en la lógica de negocio de tu producto.

🔥 Copilot pierde cuota de mercado: de 67% a 51% entre devs profesionales

GitHub Copilot bajó de 67% a 51% de share entre developers profesionales, mientras Cursor debutó con 18% y Claude Code alcanza 10%. La salida de Shuyin Zhao (VP de Copilot) a CTO de Cursor y múltiples outages aceleraron la migración.

Claude Opus 4.8 lanzado: mejor juicio, menos alucinaciones, Fast Mode 3x más barato

Anthropic lanzó Opus 4.8 el 28 de mayo con la tasa de error más baja de los 6 modelos testeados en cada benchmark. Agentic coding sube de 64.3% a 69.2%, y el Fast Mode ahora corre a 2.5x velocidad por $10/$50 M tokens —tres veces más barato que en Opus 4.7. Mismos precios estándar: $5/$25 M tokens.

Más fiable en tareas largas y auto-verificación, Fast Mode accesible —ideal para pipelines de coding agente donde antes el costo de Opus era prohibitivo.

Anthropic • Simon Willison

Claude Code: Dynamic Workflows en research preview — orquesta cientos de sub-agentes en paralelo

La nueva feature permite que Claude escriba scripts de orquestación dinámica que lanzan decenas a cientos de sub-agentes en paralelo desde una sola sesión, con agentes de verificación independientes que validan hallazgos antes de entregar resultados.
