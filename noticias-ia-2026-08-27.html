Aplicaciones profesionales de IA

🔥 Cloudflare lanza Kitesurf: browser sin Chromium construido para agentes AI

Kitesurf es un browser stateless que corre sobre Workers y V8 isolates, usando 3-7x menos CPU y memoria que Chromium. Pasa +235K tests de la Web Platform, es compatible con Puppeteer, Playwright y MCP, y está gratis en beta.

Si tu producto tiene agentes que navegan la web (scraping, automatización, testing), esto reduce drásticamente el costo de infra vs. correr instancias de Chromium headless.

TechCrunch • Cloudflare Docs

🔥 DeepSeek V4-Flash-Vision-Exp: multimodal a precio de texto

DeepSeek lanzó V4-Flash-Vision-Exp el 21 de agosto, integrando comprensión de imágenes, screenshots y diagramas en la arquitectura ultra-rápida de V4-Flash. Rinde cerca de Opus 4.8 en benchmarks de agentes multimodales, al mismo precio que el modelo de solo texto.

Para agentes que necesitan interpretar UI, gráficas o documentos escaneados, ahora hay una opción open-source competitiva sin multiplicar tu bill de API.

AWS Web Search en Bedrock AgentCore ya está en GA

AWS lanzó Web Search como herramienta managed en Amazon Bedrock AgentCore, permitiendo a agentes AI buscar en la web con citas sin que los datos salgan de la cuenta AWS del cliente. Disponible en general availability desde el 21 de agosto.

Si ya estás en el ecosistema AWS, tus agentes ahora pueden hacer búsquedas web sin integrar APIs de terceros ni preocuparte por data residency.

🔥 Gemini 3.7 Flash: el workhorse de Google para coding y agentes a mitad de precio

Google lanzó Gemini 3.7 Flash el 13 de agosto con 65.3% en DeepSWE v1.1 (vs 49% de 3.6 Flash). Disponible en Google AI Studio, Android Studio, Antigravity y la Gemini Enterprise Agent Platform, a precio introductorio de $0.75/$3.75 por 1M tokens hasta fin de 2026.

Para tu backend de agentes o features de AI en Android, 3.7 Flash ofrece la mejor relación calidad/precio del mercado en este momento.

Google Blog • 9to5Google

MCP 2026-07-28: el protocolo se vuelve stateless y modular

La nueva spec de Model Context Protocol elimina el handshake initialize/initialized, haciendo cada request auto-descriptivo. Agrega Multi Round-Trip Requests, extensions formales (Tasks, Subscriptions), y depreca Sampling, Roots y el transporte HTTP+SSE legacy con 12 meses de transición.

Si expones herramientas via MCP, esta versión simplifica tu implementación y te prepara para el mundo de agentes stateless que viene.

MCP Blog • Google Developers

Hugging Face + NVIDIA lanzan Open Data for Agents: 50K+ trayectorias de tareas

Dataset curado de más de 50,000 trayectorias de tareas para estandarizar el entrenamiento de agentes AI autónomos. En benchmarks iniciales, mejora el rendimiento de agentes entrenados con él en un 40%.

Si estás fine-tuneando agentes propios, ahora hay un dataset abierto de referencia en lugar de tener que generar datos sintéticos desde cero.

Claude Code sumó --restricted (desactiva herramientas que ejecutan código, limita file tools al working directory), messaging entre sesiones independientes vía ListAgents/SendMessage, y un tool SendFeedback que drafea reportes de bugs para tu revisión.
