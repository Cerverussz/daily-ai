🔥 Apple abre Foundation Models gratis a pequeños devs y anuncia open-source del framework

En WWDC 2026, Apple anunció que desarrolladores con menos de 2 millones de descargas en App Store pueden usar Apple Foundation Models en Private Cloud Compute sin costo. Además, el framework será open-source con soporte para Linux, permitiendo usarlo en backends no-Apple con Swift.

Si construyes para iOS, esto elimina el costo de API cloud para features de AI en tu app — y el soporte Linux lo hace viable para tu backend también.

🔥 Xcode 27 trae coding agéntico multi-modelo: Claude, Gemini y GPT en tu IDE vía MCP

Xcode 27 incluye un sistema de coding dual: un modelo local en Neural Engine para sugerencias Swift en tiempo real y una capa cloud que ruteará a Claude, Gemini u OpenAI para análisis pesado. A través de mcpbridge, cualquier agente MCP (Claude Code, Cursor, Codex) se conecta a diagnósticos live de Xcode, previews SwiftUI y el REPL de Swift.

El protocolo MCP en Xcode convierte a tu IDE en un hub universal de agentes — puedes cambiar de modelo sin tocar código, lo que reduce vendor lock-in drásticamente.

GitHub Copilot migra a AI Credits: billing por tokens activo desde junio 1

GitHub reemplazó las PRUs por AI Credits ($0.01 = 1 crédito) basados en tokens consumidos por modelo. Code completions y Next Edit Suggestions siguen ilimitados, pero todo lo demás (chat, PR review, agent mode) ahora se mide. Los planes Pro incluyen 1,500 créditos, Pro+ 7,000 y Max 20,000 mensuales.

Si dependes de Copilot en tu workflow diario, necesitas auditar cuántos créditos consume cada feature para evitar sorpresas en la factura.

🔥 Gemma 4 optimizada para Arm: inferencia on-device sub-20ms en Android

Google y Arm anunciaron Gemma 4 optimizada para chipsets Arm, logrando inferencia de producción por debajo de 20ms en dispositivos móviles. Las mejoras incluyen zero-copy buffer sharing entre la cámara HAL y el motor de inferencia, eliminando 3-5ms de overhead en pipelines de visión por computadora.

Sub-20ms en device abre la puerta a features de AI en tiempo real (cámara, AR, UX adaptativa) sin round-trip a la nube en tu app Android.

EE.UU. ordena suspender Fable 5 y Mythos 5: primer recall de un modelo AI comercial

El 12 de junio, el gobierno de EE.UU. emitió una directiva de control de exportaciones que obligó a Anthropic a desactivar Fable 5 y Mythos 5 para todos los usuarios globalmente, sin previo aviso ni periodo de migración. El motivo: una vulnerabilidad de jailbreak descubierta en Fable 5. Agentes, coding assistants y deploys enterprise construidos sobre Fable 5 en sus 3 días de vida quedaron inoperativos simultáneamente.

Este precedente cambia las reglas: si dependes de un solo modelo frontier, necesitas un fallback plan real — Opus 4.8 funciona pero no es drop-in replacement.
