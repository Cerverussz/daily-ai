Aplicaciones profesionales de IA

🔥 Meta lanza Muse Glimmer: modelo open-weight de 30B param para agentes AI locales

Meta publicó Muse Glimmer, un modelo de 29.6B parámetros bajo Apache 2.0 que corre en una sola GPU consumer o Mac con Apple Silicon. Incluye un encoder de visión de 1.8B params, contexto de 131K tokens, soporte para 100+ idiomas, y capacidad de planificar tareas, llamar herramientas, escribir código y recuperarse de errores de forma autónoma.

Un modelo agéntico que cabe en hardware local cambia la ecuación para apps Android/desktop que necesitan AI offline sin depender de APIs cloud ni pagar por token.

TechCrunch • Meta AI Research

🔥 CopilotKit open-sources Channels SDK: lleva cualquier agente AI a Slack y Teams

CopilotKit lanzó Channels SDK (MIT), una librería que conecta cualquier agente AI (LangGraph, CrewAI, Mastra, Google ADK, o HTTP custom) a Slack y Microsoft Teams con UI nativa, streaming, tool calls y manejo de archivos. Discord y Google Chat están en el roadmap.

Si estás construyendo un agente para tu producto o marketplace, esto elimina semanas de integración per-plataforma para distribuirlo donde ya están tus usuarios.

L&T lanza AgenticIQ: plataforma de agentes autónomos para manufactura e ingeniería

L&T Technology Services presentó AgenticIQ, una plataforma end-to-end para workflows autónomos multi-agente enfocada en organizaciones de ingeniería y manufactura. Orquesta agentes que pueden tomar decisiones, ejecutar tareas y coordinarse entre sí.

Señal de que los agentes AI están entrando en verticales industriales pesados, lo cual valida la oportunidad para builders que quieran crear plataformas agénticas en otros verticales.

🔥 GPT-5.6 Luna baja precios 80%: input a $0.20/M tokens, la guerra de precios se intensifica

OpenAI recortó el precio de GPT-5.6 Luna a $0.20/M input y $1.20/M output (antes $1/$6), con cached input a $0.02/M. Con contexto largo sube a $0.40/$1.80. ChatGPT ya supera los 1.000M de usuarios activos semanales.

A estos precios, Luna compite directamente con modelos open-source en costo; si tu producto usa API de OpenAI, es momento de re-evaluar si el margen de tu feature de AI acaba de mejorar drásticamente.

Claude y ecosistema Anthropic

🔥 Claude Code añade self-hosted environments: ejecuta sesiones en tu propia infra

Claude Code v2.1.224 introduce self-hosted environments en beta pública para planes Team y Enterprise. Con el comando claude self-hosted-runner, tus máquinas o contenedores se convierten en el compute layer donde corren las sesiones, accediendo a servicios internos, DBs y herramientas custom sin exponerlas a internet.

Para equipos con requisitos de compliance o que necesitan que el agente acceda a toolchains internas, esto elimina el blocker principal de adoptar Claude Code en producción.

Anthropic • Unite.AI

Anthropic introduce watermarks invisibles en texto generado por Claude

Como parte de sus compromisos bajo el EU AI Act, Anthropic embebe marcas de agua invisibles en el texto que genera Claude. La watermark no altera el significado ni la legibilidad, pero persiste cuando se copia, pega, e incluso después de cierta edición.

Si usas Claude para generar contenido en tu producto, considera que el texto ahora lleva una señal detectable de origen AI; relevante para cumplimiento regulatorio y para tus propias políticas de contenido.

Claude expandió Cowork a móvil y web, permitiendo que sesiones y archivos te sigan entre dispositivos. Incluye trabajo en background, tareas programadas, proyectos compartidos y aprobaciones desde el celular.
