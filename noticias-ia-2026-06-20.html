🔥 Windsurf es ahora Devin Desktop: Agent Client Protocol como estándar abierto

Cognition rebrandeo Windsurf como Devin Desktop con migración automática OTA. El cambio clave: soporte nativo para Agent Client Protocol (ACP), un estándar abierto JSON-RPC para conectar cualquier editor con cualquier agente de coding. Cascade (el agente local) muere el 1 de julio — reemplazado por Devin Local.

ACP es el LSP de los agentes de código — si construyes herramientas dev, implementar ACP te hace compatible con Zed, JetBrains, y ahora Devin de una sola vez.

🔥 Google AI Studio construye apps Android nativas desde un prompt

El Antigravity Agent en Google AI Studio genera proyectos completos en Kotlin + Jetpack Compose desde lenguaje natural, con acceso a sensores (GPS, Bluetooth, NFC), emulador en el navegador, e integración directa con Google Workspace. 🔥 Claude Design se renueva: imports de design systems y handoff directo a Claude Code

Anthropic lanzó una actualización mayor de Claude Design el 17 de junio: ahora importas tu design system desde GitHub, archivos de diseño o uploads, y Claude construye respetando esos componentes con auto-corrección. El handoff a Claude Code es directo (sin screenshots ni rebuilds), y el comando /design permite diseñar desde terminal.

Esto cierra el loop diseño→código para equipos pequeños: diseñas con tus componentes reales y el código generado ya los usa correctamente.

Claude Code Ultracode: orquestación multi-agente automática con Opus 4.8

Disponible desde v2.1.154 (28 de mayo), Ultracode setea esfuerzo xhigh y añade una capa de workflow dinámico que planifica, delega a sub-agentes y auto-verifica. Elimina los problemas de early quitting y goal drift en tareas grandes que un solo context window no puede resolver.

Para migraciones de codebase, auditorías de seguridad o refactors masivos, Ultracode convierte tareas de días en horas — activa con /effort ultracode.
