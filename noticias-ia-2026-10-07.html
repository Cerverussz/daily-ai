🔥 Personal Agent Protocol: Sierra y Meta definen cómo agentes AI interactúan con negocios

Sierra y Meta publicaron Personal Agent Protocol, un estándar abierto basado en OAuth que define cómo agentes AI personales se autentican e interactúan con negocios. Cuenta con el respaldo de Shopify, Stripe y Walmart, con la especificación v0.1 prevista para finales de octubre.

OpenAI Codex migra a GPT-6 Astra por defecto — GPT-5.5 se retira el 14 de octubre

OpenAI cambió el modelo por defecto de Codex a GPT-6 Astra desde septiembre, y anunció que GPT-5.5 se retirará de ChatGPT y Codex el 14 de octubre. Astra iguala el rendimiento en coding de Astra a menor costo por tarea (~$1.92 vs $9.90).

Innovaciones técnicas con potencial práctico

Mistral Large 4 “Le Chonk”: Europa lanza modelo de 1.05T parámetros MoE

Mistral liberó Mistral Large 4 en preview vía API, un modelo mixture-of-experts de 1.05 trillones de parámetros (49B activos por token) con contexto de 1M tokens y entrada multimodal. Los pesos abiertos llegarán a finales de octubre.

A ~$1.36/M input tokens con pesos abiertos inminentes, es la alternativa europea más seria para self-hosting de modelos grandes con contextos largos y razonamiento multimodal.

OpenAI libera 722 manuscritos de matemáticas generados por un agente AI autónomo

OpenAI publicó en GitHub 722 manuscritos de investigación matemática generados por un modelo interno no publicado. Según Scientific American, casi todos fueron producidos a partir de un solo prompt entregado a un agente que trabajó sobre ~4,000 problemas.

Es la demostración más concreta de que agentes AI pueden producir trabajo técnico a escala — plantea la pregunta de cuánta documentación y contenido especializado puedes automatizar en tu producto.

Claude y ecosistema Anthropic

🔥 Claude Haiku 5.5 lanzado: hasta 90% más barato, 1M de contexto y thinking adaptativo

Anthropic lanzó Claude Haiku 5.5, su modelo small más capaz, a $0.10/M input tokens para requests ≤100K tokens (vs $1/M de Haiku 4.5). Incluye contexto de 1M tokens (5x más que su predecesor), output de hasta 128K tokens, y thinking adaptativo activado por defecto. Disponible en Claude Platform, AWS, Google Cloud y Azure.

A un décimo del costo anterior, Haiku 5.5 habilita clasificación, resúmenes y subagentes en volumen que antes no eran económicamente viables — ideal como capa rápida en arquitecturas multi-modelo.

Claude Code Mods: plugins TypeScript que reescriben prompts, tool calls y UI del agente

Anthropic lanzó Mods para Claude Code, funciones TypeScript que modifican el comportamiento del agente desde adentro: reescribir prompts, agregar UI, reemplazar features built-in, o añadir funcionalidad nueva. Se distribuyen como plugins y el built-in /diff ya es un mod reemplazable.

Esto convierte a Claude Code de herramienta a plataforma extensible — puedes adaptar el agente exactamente a tu stack y workflow sin forks ni hacks.
