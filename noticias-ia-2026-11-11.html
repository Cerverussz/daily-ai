🔥 Automattic lanza Spacefast: hosting instantáneo para apps construidas con IA

Spacefast es una plataforma de Automattic que provee backend completo (base de datos, auth, file uploads, email, analytics) para proyectos generados con AI coding tools. Se publica via MCP server, API o CLI, con plugins oficiales para Claude, ChatGPT, Cursor y Antigravity.

Si estás construyendo MVPs con vibe coding, esto elimina el cuello de botella de configurar infra backend: publicas directo desde tu AI assistant por $5/mes.

🔥 Google cierra Jules: su agente de coding se fusiona con Antigravity

Google puso Jules en modo solo-lectura desde el 11 de noviembre, con cierre total el 31 de diciembre. Las capacidades de coding agente se integran en Antigravity, su plataforma agent-first que reemplazó a Gemini CLI. La guía de migración apunta a Claude Code como alternativa CLI.

Si dependías de Jules para automatizar PRs o tareas async, migra ahora a Antigravity o Claude Code antes del cierre definitivo.

Fireworks AI revela brecha de seguridad: datos de billing y model weights expuestos

Fireworks AI, proveedor de infraestructura de modelos, notificó a clientes el 9 de noviembre que un intruso accedió a máquinas de desarrollo el 24 de octubre via un cloud provider. Se expusieron datos de facturación, secrets, datasets y model weights incompletos.

Si usas Fireworks como inference provider (o cualquier tercero para hosting de modelos), este es un recordatorio de rotar secrets y auditar qué datos compartes con tu stack de inferencia.
