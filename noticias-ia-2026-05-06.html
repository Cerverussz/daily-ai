Aplicaciones profesionales de IA

🔥 CopilotKit levanta $27M y lanza AG-UI: el protocolo open-source para agentes embebidos en apps

CopilotKit cerró una Serie A de $27M (Glilot, NFX, SignalFire) para su framework que permite integrar agentes AI directamente dentro de aplicaciones existentes, no como chatbots aparte. Su protocolo AG-UI, ya adoptado por Google, Microsoft, Amazon y Oracle, estandariza cómo los agentes comparten estado, hacen streaming y manejan human-in-the-loop con las UIs de las apps.

Si estás construyendo un marketplace o SaaS, AG-UI te da la infraestructura para meter agentes AI nativos en tu producto sin inventar el protocolo desde cero.

Jama Connect lanza el primer MCP Server para software de ingeniería regulada

Jama Connect 9.35 es el primer software de gestión de ingeniería con un MCP Server nativo, permitiendo a ingenieros trabajar desde Claude, Cursor, Codex o GitHub Copilot manteniendo trazabilidad, permisos y auditoría. Los agentes AI acceden a specs y requisitos sin romper compliance en industrias reguladas.

Es un caso concreto de cómo MCP está pasando de protocolo experimental a infraestructura enterprise — si tu producto maneja datos regulados, este es el patrón a seguir.

🔥 TinyFish hace gratuitas sus APIs de Web Search y Fetch para todos los agentes AI

TinyFish abrió sus APIs de búsqueda web y fetch sin costo, sin tarjeta de crédito, con rate limits generosos. Funciona via REST API, MCP server, SDKs de Python/TypeScript, y se integra directamente con Claude Code, Cursor, Codex, LangChain y CrewAI.

Web search era el cuello de botella de pago en flujos de agentes desde 2024 — ahora puedes agregar búsqueda web a tu agente sin costo variable.

GPT-5.5 Instant es el nuevo modelo default de ChatGPT: 52% menos alucinaciones

OpenAI lanzó GPT-5.5 Instant como modelo default para todos los usuarios de ChatGPT y disponible en API como chat-latest. Reduce alucinaciones un 52% vs GPT-5.3 en prompts de medicina, derecho y finanzas, y usa 30% menos tokens en respuestas más concisas y naturales.

Si usas la API de OpenAI, el switch a chat-latest te da mejor calidad gratis — pero GPT-5.3 solo estará disponible 3 meses más, así que planifica la migración.

TechCrunch • OpenAI

🔥 GitHub Copilot CLI: plugins enterprise-managed y MCP mejorado (v1.0.43)

GitHub lanzó enterprise-managed plugins para Copilot CLI en public preview, permitiendo a admins distribuir hooks, skills y configuraciones MCP a toda la organización. La v1.0.43 corrige el ciclo de vida de procesos MCP server y añade controles de seguridad para modo prompt.

Si tu equipo usa Copilot CLI, los plugins managed significan que puedes estandarizar herramientas y MCP servers sin que cada dev configure manualmente.

IBM Think 2026: watsonx Orchestrate para multi-agente e IBM Bob para devs enterprise

IBM presentó la nueva generación de watsonx Orchestrate como plano de control para orquestar agentes de cualquier proveedor con políticas y auditoría unificada. También lanzó IBM Bob (GA), un asistente de desarrollo agéntico con controles de seguridad y costos integrados, disponible en VS Code.

El problema real de 2026 ya no es construir un agente sino gobernar cientos — watsonx Orchestrate ataca ese problema a escala enterprise.

🔥 Cofounder 2: plataforma para operar una empresa entera con agentes AI organizados en org chart

General Intelligence Company lanzó Cofounder 2 en research preview: una plataforma donde un solo founder o equipo pequeño puede correr ingeniería, ventas, marketing, soporte y ops con agentes AI especializados, cada uno con su workspace y herramientas (Linear, Slack, Notion, CRMs). Un agente manager coordina tareas y progreso entre departamentos.

Es la versión más concreta hasta ahora de “empresa de una persona” con AI — si estás bootstrapping, vale la pena probar el fellowship de $1K que ofrecen.

🔥 Anthropic firma deal con SpaceX por 300MW de compute y duplica límites de Claude Code

Anthropic accederá al 100% del datacenter Colossus 1 de SpaceX en Memphis: más de 300MW y 220,000+ GPUs NVIDIA. Como resultado inmediato, duplicó los rate limits de Claude Code en planes Pro, Max, Team y Enterprise, y eliminó las reducciones por horas pico en Pro y Max.

Más capacidad = menos throttling en tus sesiones de Claude Code — si te frenaban los límites, ahora tienes el doble de runway.

Anthropic • CNBC

Claude Managed Agents con Memory: agentes que aprenden entre sesiones (public beta)

Anthropic habilitó Memory en Claude Managed Agents en beta pública, permitiendo que los agentes de larga duración retengan contexto y aprendizajes entre sesiones con una capa de memoria optimizada. También lanzó el Advisor Tool en beta nativa en la Claude Platform.

Agentes con estado persistente cambian el juego para automatizaciones recurrentes — onboarding, soporte, procesamiento de órdenes — sin reprogramar contexto cada vez.

🔥 Google Health reemplaza Fitbit: AI Health Coach con Gemini llega el 19 de mayo

Google reemplaza la app de Fitbit con “Google Health”, que incluye un AI Health Coach construido con Gemini. El coach analiza sueño, frecuencia cardíaca, actividad y fotos de comidas para generar planes de fitness personalizados con recomendaciones diarias. También lanzó Fitbit Air ($99.99), un wearable sin pantalla enfocado en tracking 24/7.

Google está construyendo el marketplace de salud+AI que conecta datos de cualquier wearable (incluyendo Apple Watch y Garmin) — la oportunidad está en servicios profesionales que se integren a esta plataforma.
