🔥 Goldman Sachs restringe herramientas de AI coding: solo ingenieros pueden usar Claude Code y GitHub Copilot

Goldman Sachs prohibió a la mayoría de sus traders y banqueros el uso de herramientas avanzadas de AI coding como Claude Code y GitHub Copilot, limitándolas exclusivamente a ingenieros de software. La directiva interna, revisada por Bloomberg, busca controlar riesgos de seguridad y cumplimiento en el uso de AI generativa.

Señal clara de que las empresas grandes están diferenciando entre AI para devs (productividad) y AI para el resto (riesgo) — si vendes herramientas AI B2B, tu pitch de seguridad y gobernanza importa tanto como las features.

🔥 Okta Agent SSO en GA: identidad de primera clase para agentes AI, gratis en planes SSO

Okta lanzó Agent SSO como generalmente disponible, implementando el estándar abierto Cross App Access para registrar agentes AI como identidades en Universal Directory con tokens de corta duración. La capacidad viene incluida en los planes core de SSO sin costo adicional.

Si estás construyendo agentes que tocan datos de clientes en tu marketplace o plataforma, ahora tienes gobernanza de identidad enterprise-grade sin armarla a mano.

Make.com lanza AI Agents con integración MCP para workflows autónomos

Make.com introdujo Make AI Agents, permitiendo construir workflows autónomos que se conectan a herramientas externas vía Model Context Protocol (MCP). La integración permite que los agentes ejecuten acciones multi-paso sin intervención humana dentro del ecosistema de automatización visual de Make.

Para founders técnicos que ya usan Make para automatizar ops, ahora pueden escalar a agentes autónomos sin migrar a infraestructura propia.

🔥 GitHub Copilot depreca Claude Opus 5, Opus 4.8 y GPT-5.6 Terra el 16 de noviembre

GitHub anunció que el 16 de noviembre retirará Claude Opus 5, Claude Opus 4.8 y GPT-5.6 Terra de todas las superficies de Copilot: chat, edición inline, modo agente y autocompletado. Los reemplazos recomendados son Claude Opus 5.5 y GPT-6.1 Sol / GPT-6 Luna respectivamente.

Si tienes model IDs hardcodeados en configs, scripts o definiciones de agentes de tu equipo, tienes 14 días para migrar o se rompe todo.

Google Gemini 4 Carbon anunciado: más potente que Argon, aún en beta limitada

Google anunció Gemini 4 Carbon el 28 de octubre, un modelo más potente que Gemini 4 Argon (GA desde el 13 de octubre). Carbon está limitado a testers de confianza mientras Argon ya está disponible para todos los desarrolladores.

Si evalúas modelos para tu producto, Argon ya está listo para producción; Carbon es el que hay que vigilar para cuando abra acceso general.

Apple Intelligence llega a China en diciembre con iOS 27.3 usando modelos de Alibaba y Baidu

Apple confirmó que las primeras funciones de Apple Intelligence llegarán a China con iOS 27.3 en diciembre, con pruebas para desarrolladores desde el 4 de noviembre. Los features incluyen Writing Tools, Genmoji y eliminación de objetos en fotos, alimentados por Qwen de Alibaba y modelos de Baidu.

Creación de negocios y productos con IA

🔥 Copilot pierde terreno: Claude Code y Cursor alcanzan 18% cada uno en encuesta JetBrains 2026

La encuesta de JetBrains 2026 muestra que GitHub Copilot cayó de 67% a 29% entre desarrolladores profesionales, mientras Claude Code y Cursor subieron a 18% cada uno. Stack Overflow reporta una caída similar de Copilot a 51%. El mercado de AI coding se fragmentó definitivamente.

Si estás eligiendo stack de desarrollo para tu equipo o producto, ya no hay un ganador único — la estrategia es combinar herramientas según la tarea (Cursor para edición, Claude Code para terminal).

SpaceX acuerda comprar Cursor por más de $50 mil millones

Según reportes del New York Times, SpaceX llegó a un acuerdo para adquirir Cursor (Anysphere) por más de $50B. La adquisición aún no está cerrada. Es la mayor transacción en la historia de herramientas de desarrollo.

Ojo con el lock-in: si Cursor es tu herramienta principal, monitorea cómo cambian los términos de servicio y la integración de modelos post-adquisición.

Claude y ecosistema Anthropic

🔥 Anthropic activa text watermarking en Claude desde el 3 de noviembre

Desde el 3 de noviembre, Anthropic aplica marcas de agua invisibles en texto generado por Claude Mythos 5, Opus 4.7, Opus 4.6 y Sonnet 4.6 a través de la Claude Platform API. Usa la técnica SynthID-Text de Google DeepMind. Una API de detección está anunciada pero aún no disponible públicamente.

Si tu producto genera contenido con Claude para usuarios finales, prepárate para que ese contenido sea rastreable — revía tus términos de servicio y cómo comunicas el uso de AI.

Anthropic • Pasquale Pillitteri

Claude Sonnet 4.5 se retira de la API el 30 de noviembre — migra a Sonnet 5.5

Anthropic marcó Claude Sonnet 4.5 (claude-sonnet-4-5-20250929) como deprecated desde septiembre, con retiro definitivo el 30 de noviembre. Después de esa fecha, las peticiones a ese model ID fallarán sin período de gracia. El reemplazo oficial es Claude Sonnet 5.5.

Si tienes Sonnet 4.5 hardcodeado en tu backend o pipelines, tienes 28 días para migrar a Sonnet 5.5 antes de que se rompa.

Kingy AI • Layer3 Labs

Anthropic Message Threads en public beta en la Messages API

Los Message Threads de Anthropic entraron en beta pública, añadiendo un parámetro único thread a las peticiones de la Messages API. Permite conversaciones con tiempo más rápido al primer token porque cada request solo envía los mensajes nuevos en vez del historial completo.

Si tu app tiene conversaciones largas con Claude, esto reduce latencia y costos de tokens de input significativamente sin cambiar tu flujo.

🔥 Startup usa virus diseñados por AI para tratar infecciones resistentes a antibióticos en humanos

Radical Numerics, startup de California, administró por primera vez un fago (virus que ataca bacterias) diseñado completamente por su modelo de AI Omnii-1 a un paciente humano con infección resistente a antibióticos. El tratamiento se realizó bajo uso compasivo supervisado por médicos.

Es el primer caso real de AI diseñando tratamientos biológicos personalizados que llegan a un paciente — la intersección AI + biotech pasa de papers a clínica.
