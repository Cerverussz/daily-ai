Innovaciones técnicas con potencial práctico

🔥 NVIDIA Nemotron 3.5 Lightning: agentes always-on que corren en una laptop

Modelo MoE de 30B parámetros con solo 3B activos por forward pass, optimizado para agentes de larga duración con baja latencia. Incluye quantización NVFP4, speculative decoding, y hasta 4x velocidad de output vs modelos similares. Viene con NeMo Switchyard, un router open-source que enruta cada paso del workflow al mejor modelo.

Un modelo de agentes que corre en GPU de laptop cambia la ecuación para features de AI offline en tu app, especialmente si combinas con edge computing en Android.

NVIDIA Blog • CNBC

🔥 Meta Muse Glimmer: 30B open-source multimodal para agentes on-device

Modelo de 30B params destilado de Muse Spark, bajo Apache 2.0, con visión integrada (2B ViT encoder + 28B decoder). Corre en un solo GPU de consumo (24GB VRAM) e incluye build ExecuTorch para ejecución on-device. Lidera benchmarks agentic: MCP Atlas 75.5, SWE-Bench Pro 51.2.

Un modelo multimodal con tool-use y recovery de fallos que corre local y es Apache 2.0 es exactamente lo que necesitas para features de AI embebida en tu producto sin depender de cloud.

Meta Research • InfoQ

A2A de Google se une al Agentic AI Foundation junto a MCP: los estándares de agentes bajo un mismo techo

El 20 de agosto, el protocolo Agent-to-Agent (A2A) de Google se unió a la Agentic AI Foundation de la Linux Foundation, la misma entidad que gobierna MCP de Anthropic. AAIF ya tiene 250+ miembros incluyendo Google, Microsoft, Amazon, OpenAI y Anthropic.

MCP conecta agentes con herramientas (vertical), A2A conecta agentes entre sí (horizontal); ambos bajo gobernanza neutral significa que puedes apostar por estos estándares sin lock-in.

Claude y ecosistema Anthropic

🔥 Claude Sonnet 5 congela precio en $2/$10 permanentemente (pero ojo con el tokenizer)

Anthropic confirmó que el precio introductorio de Sonnet 5 ($2/$10 por millón de tokens) es ahora el precio estándar; la subida a $3/$15 del 1 de septiembre fue cancelada. Sin embargo, el nuevo tokenizer genera ~30% más tokens, lo que puede significar un aumento efectivo de costo en algunos workloads.

Buena noticia para tu presupuesto de API, pero haz benchmark real de tu consumo de tokens con el nuevo tokenizer antes de asumir que pagas lo mismo.

ExplainX • Enterprise DNA

Claude Code: restricted mode, cross-session messaging y self-hosted runners

Claude Code v2.1.224+ (agosto) trae restricted mode para entornos controlados, cross-session messaging (sesiones de Claude Code que se comunican entre sí via ListAgents/SendMessage), y self-hosted runners. La v2.1.251 expandió messaging a Bedrock, Vertex y Foundry.

Cross-session messaging habilita workflows multi-agente reales donde un agente delega subtareas a otro, algo que antes requería orquestación externa.
