Aplicaciones profesionales de IA

🔥 Google mata Gemini CLI: Antigravity CLI llega con free tier recortado a ~20 requests/día

El 18 de junio Google cerró definitivamente Gemini CLI para usuarios free, Pro y Ultra. El reemplazo es Antigravity CLI, un binario cerrado en Go que reduce el free tier de 1,000 a ~20 requests diarios. Los pipelines CI/CD que dependían del comando gemini dejaron de funcionar inmediatamente.

Si tenías scripts o automatizaciones con Gemini CLI, migra hoy a Antigravity o evalúa Claude Code / Codex CLI como alternativas con mejores límites.

Cognizant lanza orquestación cross-platform de AI Agents con ServiceNow vía MCP

Cognizant anunció que los AI Agents de ServiceNow ahora interoperan con Cognizant Neuro AI Multi-Agent Accelerator, una plataforma open-source que usa MCP para descubrir e invocar agentes de múltiples vendors sin conectores custom. La integración permite orquestar agentes de ServiceNow junto con sistemas propios y de terceros desde un solo panel.

Valida que MCP se está convirtiendo en el estándar real para interoperabilidad entre agentes enterprise; si construyes servicios B2B, exponer via MCP ya no es opcional.

🔥 Apple abre Foundation Models a terceros: Claude y Gemini via Swift API + PCC gratis para devs pequeños

En WWDC 2026, Apple anunció que open-sourcea su Foundation Models framework y da acceso gratuito a Private Cloud Compute para desarrolladores con menos de 2M descargas en App Store. El framework ahora soporta modelos de terceros (Claude, Gemini) via la misma Swift API, y añade Dynamic Profiles para workflows multi-agente.

Si desarrollas para iOS/macOS, ahora tienes AI on-device + cloud gratis con acceso a los mejores modelos del mercado desde una sola API nativa.

MacRumors • Apple Developer

Claude Code semana 24: sub-agentes recursivos, /cd mid-session y safe mode

Las últimas actualizaciones de Claude Code incluyen sub-agentes que pueden crear sus propios sub-agentes (hasta 5 niveles de profundidad), el comando /cd para cambiar de directorio sin perder contexto, --safe-mode para troubleshooting, y configuración de fallbackModel con hasta 3 modelos de respaldo.

Los sub-agentes recursivos cambian cómo puedes atacar refactors grandes o migraciones multi-módulo desde la terminal.

Codex CLI y Claude Code empatan en Terminal-Bench 2.1: 83.4% vs 83.1%

El benchmark Terminal-Bench 2.1 muestra a Codex CLI (GPT-5.5) liderando con 83.4% y Claude Code (Fable 5) en 83.1%, un empate técnico. Sin embargo, con la suspensión de Fable 5, Codex CLI es temporalmente el único coding agent disponible operando en el tope del ranking.

La paridad real entre coding agents significa que tu elección debe basarse en integraciones y workflow, no en benchmarks; hoy la disponibilidad de Fable 5 pesa más.

🔥 Modelos open-weight ganan tracción enterprise post-Fable 5: Kimi K2.7 Code, GLM-5.2 y Llama 4

Con la suspensión de Fable 5, empresas están evaluando activamente alternativas open-weight.
