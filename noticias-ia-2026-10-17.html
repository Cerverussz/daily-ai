🔥 DeepSeek lanza V4.1-Flash-1017 y abre Search & Fetch APIs para desarrolladores

DeepSeek publicó un nuevo checkpoint de su modelo Flash bajo licencia MIT con contexto de 1M tokens, logrando 77.0 en DeepSWE v1.1. Simultáneamente abrió sus APIs de Search y Fetch a todos los desarrolladores a $0.75 por cada 1,000 llamadas, con acceso gratuito vía server-side tools hasta el 1 de noviembre.

Si construyes agentes que necesitan búsqueda web, ahora tienes modelo de coding + búsqueda detrás de una sola API key a precio agresivo.

Anthropic lanza trazas OpenTelemetry para agentes y la Messages API

La Claude Platform ahora exporta trazas OpenTelemetry desde Managed Agents, la Messages API y los Claude SDKs hacia cualquier backend compatible con OTLP. Las trazas cubren turnos del agente, llamadas al modelo, tool use y llamadas MCP, con latencia y conteo de tokens incluidos.

Si corres agentes Claude en producción, esto te da observabilidad real sin armar instrumentación custom — conecta directo a Datadog, Grafana o Langfuse.

DevOps.com • OpenObserve

Google abre Harness² en open source: mejora agentes sin reentrenar el modelo

Google publicó Harness², un framework Apache 2.0 que optimiza recursivamente el harness de ejecución de un agente AI (prompts, herramientas, flujo) sin tocar los pesos del modelo. Reporta +11.5 puntos en WorkBuddy-Bench con ejecutores OpenCode y Codex.

Para quienes construyen agentes sobre modelos congelados (como API calls), esto sistematiza la optimización del "wrapper" que normalmente haces a mano.

🔥 Reflection AI libera Beam bajo Apache 2.0: 501B params, 80.9% en SWE-bench Verified

Reflection AI publicó los pesos de Beam, un modelo MoE de 501B params (23B activos) con contexto de 1M tokens, bajo licencia Apache 2.0 en Hugging Face. Incluye Mirror CLI, el harness de agentes open-source usado durante su entrenamiento, con API gratuita en beta pública.

Un modelo de coding competitivo con licencia Apache 2.0 sin restricciones de uso comercial — ideal para pipelines propietarios donde no quieres dependencia de proveedor.

Meta lanza Muse Spark Open: 816B params open-weight para coding y agentes

Meta liberó la versión open-weight de Muse Spark: un modelo MoE de 816B params totales (42B activos) con contexto de 1M tokens, multimodal (texto, imagen, video, audio). Pesos disponibles en Hugging Face en BF16 y NVFP4, con hosting en AWS, GCP y Azure.

Es el modelo open-weight más grande de Meta hasta la fecha para tareas agénticas, aunque necesita hardware serio (1TB RAM para local) — útil como backend vía API hosted.

TechCrunch • Meta AI • MarkTechPost

🔥 NVIDIA lanza Nemotron 3.5 Super VL y Bolt: modelos abiertos del datacenter al edge

NVIDIA publicó Nemotron 3.5 Super VL (120B params, 12B activos), un modelo multimodal para agentes always-on con throughput hasta 5x mayor que competidores abiertos. También lanzó Bolt 74B-A9B (24GB) para desktop y Bolt E4B (4GB) para edge, con soporte para Ollama, llama.cpp y vLLM.

Bolt E4B a 4GB abre la puerta a agentes AI en dispositivos móviles y edge sin cloud — relevante si estás explorando on-device features para tu app.

NVIDIA Blog • Unite.AI • The Decoder

Gemini 4 Argon ya disponible en API: $2/M input tokens con contexto de 1M

Google hizo GA de Gemini 4 Argon con acceso expandido vía API, Antigravity CLI, app Gemini y AI Mode en Search. Precio introductorio de $2/M input y $10/M output hasta noviembre 30, con 95% de descuento en cached input. Modelo estable: gemini-4-argon.

A $2/M input es competitivo para volumen alto; el descuento de 95% en cache lo hace especialmente atractivo para RAG y procesamiento repetitivo de documentos.

🔥 Claude Code Mods: sistema oficial de plugins para personalizar tu agente de coding

Anthropic lanzó el sistema de Mods para Claude Code: funciones TypeScript que pueden reescribir prompts, agregar UI custom, reemplazar features built-in o añadir funcionalidad nueva. Se instalan desde el directorio .claude o con /plugin en la CLI, y la v2.1.302 mejoró el arranque con múltiples plugins.

Puedes construir mods específicos para tu codebase (linting rules, deploy shortcuts, context injection) — convierte Claude Code de herramienta genérica a asistente especializado para tu producto.

Google lanza protecciones AI anti-scam en Android con Gemini Nano on-device
