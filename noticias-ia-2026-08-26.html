🔥 IBM lanza Granite 4.2 open-weight: modelos con RL agéntico y 512K de contexto

🔥 Alibaba lanza Qwen3.8-Flash-Next: preview de la arquitectura Qwen4 con N-gram embedding

Modelo MoE multimodal de 125B params con solo 6B activos por token. Introduce una capa de N-gram embedding de 51B params que almacena frases comunes como entradas independientes y puede residir en RAM del sistema en vez de GPU. Entrenado con 1/9 de los recursos de Qwen3.7-Plus.

La técnica de N-gram embedding podría reducir drásticamente el costo de inference on-device — vale seguirle la pista para apps Android con AI local.

Z.ai open-sourcea GLM-5.3-Flash: el “Ox Alpha” era un modelo de 320B multimodal

Z.ai reveló que el modelo anónimo “Ox Alpha” que lleva una semana corriendo en OpenRouter es GLM-5.3-Flash: 320B total, 18B activos, 1M tokens de contexto, nativo multimodal, bajo licencia MIT. Corre íntegramente en chips AI fabricados en China.

A $0.075/M input tokens, es el modelo multimodal con mejor ratio calidad/precio para tareas de alto volumen como extracción de datos o clasificación de imágenes.

🔥 GitHub Copilot migra a Polaris: Microsoft reemplaza GPT-4 Turbo con modelo propio

Desde agosto, Copilot migra automáticamente a Project Polaris, un MoE in-house de Microsoft con sub-módulos especializados por lenguaje. Corre en chips Maia propios, supera a GPT-4 Turbo en HumanEval/MBPP, y ofrece 100K líneas de contexto para Pro. Enterprises tienen 3 meses para hacer opt-out.

Si usas Copilot, tu modelo de coding cambió sin que lo pidieras — vale testear si la calidad en tu stack específico mejora o empeora antes de que cierre la ventana de fallback.

🔥 Headlong: harness open-source que mantiene agentes AI debuggeando código a $1-2/hora

Laude Institute open-sourceó Headlong, un harness de menos de 10K líneas de Bash que mantiene un LLM en un loop continuo de inner-monologue auto-guiado. Las demos muestran un agente llamado Audel debuggeando código autónomamente por $1-2 la hora.

Cloudflare Kitesurf: un browser diseñado para agentes AI, no para humanos

Browser en Rust/WASM que corre en Workers, usa 3-7x menos CPU y memoria que Chromium eliminando todo lo que un agente no necesita (tabs, temas, rendering pixel-perfect). Soporta Chrome DevTools Protocol, así que herramientas existentes funcionan cambiando un parámetro. Será open-source.

Si construyes agentes que scrapean o interactúan con web, esto baja el costo de infraestructura de browser automation dramáticamente.

Claude y ecosistema Anthropic

🔥 Anthropic lleva a GA: Computer Use, Browser Use, Skills API y Files API

Cuatro herramientas salen de beta en la Claude Platform. Computer Use permite a agentes operar software visual (click, type, scroll). Browser Use da a Claude una vista estructurada de páginas via accessibility tree. Skills API simplifica subir expertise reutilizable. Files API ofrece 5x más storage y expiración automática.

Browser Use cambia el juego: en vez de screenshots + coordenadas, tu agente navega webs con la precisión del accessibility tree — menos tokens, menos errores, más confiable para producción.

🔥 Technogym lanza BioStrength: máquinas de fuerza con AI adaptativa integrada

Línea de equipos de strength training con motor de resistencia que reemplaza el stack de pesas tradicional. AI ajusta automáticamente carga, tempo, rango de movimiento y protocolos (pirámides, drop sets, super slow) basándose en el perfil y rendimiento histórico de cada usuario al hacer login.

Es el modelo a seguir para marketplaces de fitness: hardware + AI + perfil de usuario = retención; la oportunidad está en replicar esta personalización en software para entrenadores independientes.
