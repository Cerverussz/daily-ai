GitHub Copilot migra a facturación por uso con AI Credits desde el 1 de junio

GitHub reemplazó los Premium Request Units por AI Credits basados en consumo de tokens por modelo. Code completions y Next Edit Suggestions siguen ilimitados, pero todo lo demás (chat, agentes, reviews) ahora se mide y factura según tokens consumidos. Copilot Pro+ cuesta $39/mes con $39 en créditos incluidos.

Revisa tu consumo real de Copilot: si usas mucho el chat o agentes, podrías terminar pagando significativamente más que antes con el modelo flat.
