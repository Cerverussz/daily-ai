🔥 Stripe adquiere OpenRouter por más de $7B: el routing de modelos AI se convierte en infraestructura de pagos

Stripe finalizó la compra de OpenRouter, el gateway que conecta a 8 millones de developers con más de 400 modelos de AI (OpenAI, Anthropic, Google, Meta, DeepSeek). El precio representa un markup de 5.4x sobre la valuación de $1.3B de su Serie B en mayo 2026.

Si tu producto consume múltiples modelos de AI, Stripe está apostando a ser el billing layer entre tu app y los proveedores — esto va a cambiar cómo monetizas features de AI.

🔥 Meta lanza Muse Code: agente de coding en terminal con sub-agentes paralelos

Meta Superintelligence Labs lanzó Muse Code en beta, un agente de coding en terminal que compite directamente con Claude Code y Copilot. Usa Muse Spark 1.2, soporta sub-agentes paralelos en worktrees aislados, sandbox de OS por defecto, y cuesta $1.25/$4.25 por millón de tokens — o $0.10/$0.20 si permites entrenar con tu código.

Un competidor serio a un tercio del precio de Claude Code — vale la pena probarlo para tareas de volumen alto donde el costo por token importa.

🔥 Meta open-sources Muse Glimmer: modelo agéntico de 30B que corre en una GPU consumer

Meta liberó Muse Glimmer bajo Apache 2.0, un modelo de 30B parámetros optimizado para agentes locales. Con cuantización a 4-bit cabe en 18-20 GB de VRAM, soporta 131K tokens de contexto, visión multimodal, y logra scores de referencia en MCP Atlas (75.5) y SWE-Bench Pro (51.2).

Si quieres agentes AI corriendo localmente en tu máquina de desarrollo o en edge devices sin depender de APIs cloud, este es el mejor modelo open-weight disponible hoy.

Anthropic activa watermarking invisible en todos los outputs de Claude

Anthropic implementó marcas de agua imperceptibles usando SynthID Text (de Google DeepMind) en todas las respuestas de Claude — API, Claude Code, Cowork y Tag. Las marcas sobreviven copy-paste, no afectan calidad ni velocidad, y una API de detección viene en camino.

Si generas contenido con Claude para tu producto, necesitas saber que ahora lleva watermark detectable — esto cambia cómo manejas atribución y compliance.

Opus 5 es default en Claude Code Max con 89.1% en Terminal-Bench

Claude Code ahora usa Sonnet 5 en planes Pro y Opus 5 en Max por defecto. Opus 5, lanzado el 24 de julio, alcanzó 89.1% en Terminal-Bench 2.1 a esfuerzo máximo, consolidándose como el modelo de coding más capaz en tareas complejas de terminal.

Si ya pagas Max, tu Claude Code ahora usa el mejor modelo de coding disponible sin cambiar configuración — reevalua si vale el upgrade desde Pro.

🔥 Claude Code: auto mode es default desde el 14 de agosto

Desde el 14 de agosto, nuevas sesiones en Pro, Max y Team arrancan en auto mode — Claude Code ejecuta acciones sin pedir aprobación salvo que sean irreversibles, destructivas, o fuera del entorno. Enterprise y API mantienen el modo anterior como opt-in.

Menos fricción en tu workflow diario, pero revisa tus deny rules antes de dejar que el agente opere sin supervisión.

Claude Code: self-hosted runners y cross-session messaging

Claude Code añadió self-hosted environments que convierten tus máquinas o containers en runners para sesiones web/móvil/desktop (Team y Enterprise). También activó messaging entre sesiones en macOS y Linux, permitiendo pasar contexto sin re-explicar.

Self-hosted runners eliminan la dependencia de infra cloud de Anthropic para equipos con requisitos de seguridad o compliance estrictos.
