Aplicaciones profesionales de IA

🔥 Google Antigravity 2.0: plataforma multi-agente de coding con CLI, SDK y desktop

Google lanzó Antigravity 2.0 en I/O 2026, una reconstrucción completa de su plataforma de coding que combina un IDE de escritorio, un CLI en Go y un SDK para crear agentes personalizados, todo corriendo sobre Gemini 3.5 Flash a 289 tokens/segundo. Un agente manager descompone tareas en subtareas y múltiples agentes especializados trabajan en paralelo, con soporte para subagentes dinámicos y tareas programadas en background.

Es el primer competidor directo que iguala la arquitectura multi-agente de Claude Code en terminal — gratis en preview para individuos, vale probarlo como alternativa para flujos de desarrollo complejos.

SAP integra Claude en su Business AI Platform via MCP — 200+ agentes enterprise

En Sapphire 2026, SAP anunció que Claude será el modelo principal de razonamiento integrado en toda su suite: agentes que cierran libros contables, responden consultas de RRHH y redirigen órdenes a proveedores, coordinando entre S/4HANA, SuccessFactors y Ariba. La integración usa Model Context Protocol (MCP) para conectar Claude con los sistemas SAP.

MCP deja de ser experimental — si SAP lo usa para conectar agentes AI con ERPs de Fortune 500, cualquier SaaS que exponga su API via MCP gana acceso a esa misma capa de agentes.

Claude Mythos aparece brevemente en Claude Code — se acerca el lanzamiento público

El 25 de mayo, usuarios detectaron un toggle de “Mythos” en la interfaz de Claude Code antes de que desapareciera. Mythos es el modelo más avanzado de Anthropic, originalmente restringido al programa Project Glasswing donde ~50 partners descubrieron más de 10,000 vulnerabilidades de alta severidad en software open-source.

Cuando Mythos llegue a Claude Code para todos, será un salto significativo en capacidad de razonamiento sobre código y seguridad — vale tenerlo en el radar para auditorías de tu codebase.

🔥 GitHub Copilot pausa nuevos registros y migra a billing por tokens el 1 de junio

GitHub suspendió sign-ups para Copilot Pro, Pro+ y Student mientras prepara la transición a billing basado en consumo de tokens el 1 de junio. Cada plan incluirá créditos mensuales de AI ($10 en Pro, $39 en Pro+), y el uso se calculará por tokens consumidos incluyendo input, output y cache.

Los flujos agénticos consumen mucho más que autocompletado — si dependes de Copilot, revisa tu consumo proyectado antes del 1 de junio para evitar sorpresas en la factura.

🔥 Gemma 4 optimizada en ARM: AI multimodal on-device para apps Android

ARM publicó optimizaciones de Gemma 4 usando Scalable Matrix Extension 2 (SME2) en procesadores Arm C1, acelerando cargas de trabajo AI sin salir del presupuesto energético de un smartphone. El modelo soporta texto, audio e imagen on-device, con capacidades de razonamiento y workflows agénticos sin conexión a cloud.

Esto reduce latencia hasta 90% y elimina costos de API en features de AI para tu app Android — ideal para experiencias offline en mercados con conectividad irregular.

Creación de negocios y productos con IA

🔥 Code with Claude: Anthropic presenta Dreaming, Outcomes y Add-ins

En el evento Code with Claude (SF + Londres), Anthropic lanzó cinco features: Dreaming (agentes escriben notas para otros agentes, acelerando onboarding en el mismo codebase), Outcomes (definir resultados esperados, no solo instrucciones), orquestación multi-agente, Claude Finance con 10 agentes pre-construidos, y Add-ins para extensiones de terceros.

Dreaming y Outcomes cambian cómo trabajas con agentes de código — en vez de repetir contexto en cada sesión, los agentes aprenden del trabajo previo, lo cual escala tu velocidad de desarrollo individual.

🔥 Google resetea pricing de AI: Ultra baja de $250 a $100/mes, Antigravity gratis en preview

Google reestructuró sus planes de AI: AI Plus a $7.99/mes, AI Pro a $19.99/mes, y AI Ultra (antes $250) a $99.99/mes con 5x más límites de Antigravity. Además, Gemini reemplazó límites diarios de prompts por un modelo de compute que se refresca cada 5 horas.
