🔥 “Agentjacking”: la nueva amenaza de seguridad para AI coding agents

Emerge un vector de ataque de prompt injection dirigido específicamente a agentes de coding AI. Los atacantes crean reportes de error falsos con instrucciones ocultas en markdown que los agentes interpretan como guía legítima, inyectando potencialmente código malicioso en proyectos.

Si usas cualquier AI coding agent, revisa el código generado con el mismo escepticismo que PRs de terceros; nunca permitas auto-commit a ramas de producción sin revisión humana.
