Aplicaciones profesionales de IA

EU AI Act entra en vigor: obligaciones de transparencia ya son ejecutables

Desde el 2 de agosto, la Comisión Europea comenzó a aplicar el AI Act. Chatbots deben avisar que el usuario habla con IA, los deepfakes requieren etiquetado, y el contenido generado por IA debe llevar marcas legibles por máquina. Multas de hasta 15M EUR o 3% de facturación global.

Si tu producto usa IA y tiene usuarios en Europa, necesitas revisar tu UX hoy: disclosure explícito en chatbots y marcado de contenido generado ya no son opcionales.

European Commission • Digital Strategy EU

Hacker usa DeepSeek + Hermes Agent para lanzar ataques autónomos vía Telegram

Palo Alto Networks (Unit 42) documentó un actor chino que conectó DeepSeek al framework Hermes Agent, controlado via Telegram, para escanear y atacar 460+ servidores expuestos de forma autónoma. El agente descargó exploits públicos, evaluó targets y ejecutó ataques con mínima intervención humana.

Primer caso documentado de ataque cibernético completamente agente: si expones APIs o servicios, el atacante ya no es un humano con scripts sino un LLM que decide qué explotar.

OpenAI anuncia Astra: modelo multi-agente que resolvió 10 problemas matemáticos abiertos por $2,000

OpenAI presentó Astra, su próxima familia de modelos, diseñada como sistema multi-agente que trabaja horas o días en problemas complejos. Una versión interna resolvió 10 problemas abiertos por décadas en matemáticas y CS teórico, incluyendo la existencia de grupos no-sóficos, publicando pruebas verificables en Lean 4.

El patrón multi-agente con verificación formal es el blueprint para agentes de producción confiables; si construyes agentes, estudia cómo Astra encadena razonamiento + validación.

🔥 Google cancela app AI Studio para móvil y mete todo en Gemini

Google canceló la app móvil de AI Studio (800K+ pre-orders desde I/O 2026) y decidió integrar sus features de creación de apps directamente en la app de Gemini para móvil y desktop. La web de AI Studio se mantiene para desktop.

Para devs Android, la señal es clara: Gemini es el único punto de entrada de Google para IA generativa en móvil; consolida tu integración ahí.

🔥 GitHub Copilot cae al 51% de mercado; Claude Code preferido por 46% de senior devs

Según el Stack Overflow Developer Survey 2026, Copilot bajó de 67% a 51% mientras Cursor debutó con 18% y Claude Code con 10%. En la encuesta de JetBrains, 46% de devs con 10+ años de experiencia eligieron Claude Code como su herramienta principal vs. 9% para Copilot.

🔥 El foco de productos AI en agosto: coding agents, wearables y robótica industrial

Los lanzamientos de agosto 2026 se concentran en tres áreas: herramientas de coding agente (Claude Code, Cursor 3, Windsurf), workflows manos-libres via wearables (Meta glasses + sEMG de muñeca), y robótica industrial (Boston Dynamics + DeepMind). El mercado premia tools que funcionan, no demos.

🔥 Claude Code sube a Opus 5: 1M de contexto, mejor coding agente, mismo precio

Claude Code ahora usa Opus 5 como modelo default (desde julio 24). Ofrece 1M tokens de contexto, 128K de output, mejor memoria en tareas largas y auto-verificación mejorada. Mantiene precio de $5/$25 por millón de tokens. Fast mode a 2.5x disponible.

Más contexto + mejor auto-verificación significa menos errores en refactors grandes y migraciones; ideal si usas Claude Code para tareas de arquitectura.

Anthropic extiende boost de uso de Claude Code hasta el 19 de agosto

El boost temporal del 50% en límites semanales de Claude Code para suscriptores se extendió hasta el 19 de agosto de 2026. Además, el pricing promocional de Sonnet 5 ($2/$10 por millón de tokens) termina el 31 de agosto, subiendo a $3/$15 en septiembre.
