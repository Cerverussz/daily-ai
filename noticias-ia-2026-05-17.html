🔥 OpenAI unifica ChatGPT, Codex y API en una sola plataforma agéntica bajo Greg Brockman

OpenAI anunció la fusión de ChatGPT, Codex y la API de desarrolladores en un único equipo de producto liderado por su presidente Greg Brockman. 🔥 Vercel Labs lanza Zero: lenguaje de programación diseñado para que agentes AI lean, reparen y desplieguen software

Zero es un lenguaje de sistemas experimental (v0.1.1, Apache 2.0) que genera binarios nativos de <10 KiB. Su compilador emite diagnósticos en JSON con códigos estables y metadata de reparación tipada, permitiendo a agentes AI parsear y actuar sobre errores sin interpretar texto humano.

Es la primera señal concreta de que la infraestructura de desarrollo se está rediseñando desde cero para agentes, no solo adaptándose — si construyes tooling, este es el patrón a seguir.

🔥 OpenAI Codex llega al móvil: supervisa y aprueba tareas de tu agente de coding desde el teléfono

OpenAI lanzó Codex en la app móvil de ChatGPT para iOS y Android, disponible en todos los planes incluyendo Free. El teléfono funciona como superficie de control para sesiones de Codex corriendo en desktop — puedes revisar diffs, aprobar comandos, cambiar modelos y seguir output del terminal en tiempo real.

Esto elimina el cuello de botella de “estoy lejos del laptop y mi agente necesita aprobación” — crítico si usas agentes autónomos para tu producto.

TechCrunch • BuildFastWithAI

xAI lanza Grok Build: agente de coding CLI con 8 agentes en paralelo y Arena Mode

xAI lanzó Grok Build en beta temprana, un agente CLI que ejecuta hasta 8 agentes AI simultáneos en un workflow de tres etapas: plan, search y build. Incluye Arena Mode, una capa de evaluación automatizada que puntea y rankea outputs competidores antes de que el dev los revise. El modelo base (grok-code-fast-1) logra 70.8% en SWE-Bench.

A $0.20/M tokens input y con ejecución local-first (sin envío de código a servidores), es una opción a evaluar para codebases propietarios.

Google confirma: prompt injection ya ataca agentes AI en producción a través de páginas web

Investigadores de Google documentaron un aumento del 32% en detecciones de prompt injection malicioso entre noviembre 2025 y febrero 2026. Páginas web públicas están inyectando instrucciones ocultas que secuestran agentes AI con acceso a email, calendarios y sistemas enterprise, incluyendo un caso donde un mensaje en código Morse robó $150K de una crypto wallet.

Si tu producto conecta agentes AI a datos externos (web, docs, emails), necesitas una capa de sanitización de contexto — esto ya no es teórico.

🔥 Claude for Small Business: 15 workflows agénticos con QuickBooks, PayPal, HubSpot y más, gratis con tu plan

Anthropic lanzó Claude for Small Business como toggle dentro de Claude Cowork, con 15 workflows agénticos preconfigurados que conectan QuickBooks, PayPal, HubSpot, Canva, DocuSign, Google Workspace y Microsoft 365. SiliconANGLE • Technobezz

ArXiv implementará ban de un año a investigadores que suban papers con contenido AI sin verificar

ArXiv anunció que autores que envíen papers con evidencia de uso descuidado de LLMs (referencias alucinadas, comentarios al modelo, texto sin revisar) enfrentarán un ban de un año, y sus envios posteriores deberán ser aceptados primero por una revista peer-reviewed. El uso de AI para editar o mejorar texto sigue permitido.

La señal es clara: AI como herramienta de productividad es bienvenida, AI como reemplazo sin supervisión no — el mismo principio aplica al código que generas con tu coding assistant.

🔥 Claude Code Agent View: gestiona múltiples agentes AI desde un solo CLI

Anthropic lanzó Agent View para Claude Code en Research Preview, permitiendo iniciar agentes, enviarlos al background, ver su status y últimas respuestas, y saltar a sesiones solo cuando necesitan input. Disponible con el comando claude agents en planes Pro, Max, Team, Enterprise y API.

Si ya usas Claude Code para múltiples tareas en paralelo, esto elimina el tab-switching entre terminales — es el dashboard que faltaba para workflows agénticos serios.
